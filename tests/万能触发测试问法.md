# 短剧创作者中心 skill 系统 · 万能触发测试问法

用途：检验 50 个 skill 能否在该用的时候被正确调用、不该用的时候不被调用。每次改动任何 skill 的 description、新增或删除 skill、平台改版后，都用这套问法回归一次。

## 一、怎么跑

1. **盲测**：把 50 个 skill 的名称与 description（只给这两项，不给正文）和下列问法交给一个没有参与设计的模型或同事，问法顺序打乱、隐去"应调用"列，让对方逐条回答"调用哪个 skill，或都不调用"，并给出第二可能的 skill。
2. **实测**（可选）：在装好整套 skill 的 Claude 里逐条输入问法，看实际加载了哪个 skill。
3. **判分**：只认第一选择，选中"应调用"或"也可接受"列都算命中。"应调用"写 NONE 的，选任何本系统 skill 都算误触发。
4. **验收标准**：正例命中率不低于 90%；负例正确率不低于 90%；同一对易混 skill 不能出现双向误判。
5. **失败处理**：失败几乎都出在 description。先看是"容易误调用"列里的哪个 skill 抢走了，再把两者的区分点写进各自的描述与"不应触发于"里，然后整套重跑，不要只改到这一条过关为止。

## 三、扩充规则

- 每个 skill 至少 2 条：一条规范说法、一条口语说法；口语说法要像真人会打的字，可以有错别字、省略主语、只说半句
- 每对易混 skill（真人与漫剧同名、诊断与创作同主题、办事与诊断同环节）至少各有一条问法互为"容易误调用"
- 负例要找"共享关键词但其实要别的东西"的请求，比如提到"剧本""分镜""漫剧"但不在短剧创作者中心范围内
- 新增 skill 时同步追加问法，编号顺延，不改旧编号，便于前后对比

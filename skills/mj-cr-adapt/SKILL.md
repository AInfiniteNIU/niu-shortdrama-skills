# AI漫剧 · 改编（mj-cr-adapt）

目标：把网文**重新排成漫剧的戏**。平台将"小说直转"列为直接拒稿项，并指出当前占比最高的差本是"把原著章节喂给 AI 一键转成剧本格式"得到的（M5-00）。

## 五道闸（第四层通用，动笔前先过）

1. **字数闸**：长篇超过 70 集、全剧不低于 7 万字（折算约每集 1000 字），单集观看 1 到 2 分钟（M1-01、M1-02）
2. **纯剧本闸**：投稿正文只能是纯剧本，分镜、提示词、资产卡、运营标注、修改痕迹一律不进正文（M2-08）；说明放进独立的"创作备忘"
3. **旁白闸**：不写叙述旁白与第一人称解说；成品框架分成合作不收旁白解说类（M1-04、M4-13）；OS 依附人物，VO 写明声源（M3-07）
4. **红线闸**：漫剧红线比真人剧更严（G4 加 M8），剧本里写的都会被画出来
5. **依据闸**：行业数据、播放量、分账倍数不作依据；平台没写的只作经验参考并注明"非平台规则"

## 平台校准

- 自有 IP 或平台授权（G5-01、G5-02）；IP 漫剧必须关联对应番茄 IP（M1-07）
- 获得成品框架分成后自动开通 IP 库，每月可改编数量有额度；超出部分可向番茄原创自行采买，自行采买的 IP 上传时"是否 IP 改编"填"否"（M1-06）
- 投稿模板第 2、3 项填是否 IP 改编、IP 小说名与 IP 编号（M2-01）
- 不选已改编成大火漫剧或已有多版本的 IP 做无本质变化的改编（M6-08）
- 不可删信息清单与设定状态表（M5-04）；设定精炼，不轰炸也不一刀删（M5-07）
- 不按章节平铺（M5-01）；做减法（M5-09）；不魔改（M5-11）
- AI 可以辅助摘要、梳理、脑暴、局部扩写；判断原著价值、设计改编方案、重构开篇与分集、设计关键因果、终稿精修由编剧完成（M5-14），本 skill 的方案需编剧确认

## 工作流程

1. **权属与 IP 信息**：IP 小说名、IP 编号、授权或采买状态
2. 解构、守恒与不可删清单（见下）
3. **篇幅与连载**：原著按弧线切成剧的四阶段；选戏剧密度最高的弧线深做；定承诺总集数（超过 70 集）与首发批次
4. **漫剧转写**：叙述与心理改为多角色当面对抗和可画动作（不转旁白解说，M1-04）；多视角收束为单一主视角；章末钩子转集尾；蓄力压缩、快速兑现；名场面做成视觉奇观，同时演出完整情绪链；不照搬原文字句
5. **交接**：交 mj-cr-world（世界观）、mj-cr-character（人设与形象锚点）、mj-cr-outline（大纲）、mj-cr-opening、mj-cr-episode

### 解构五件套
1. 母题一句话
2. 人物内核（主要角色各一句：他无论如何不会背叛什么）
3. 名场面清单 5 到 10 个，标注情绪功能
4. 情感线测绘（关系如何一步步变化）
5. 世界规则提取（不超过 5 条核心规则）

### 三大守恒与不可删清单
母题、人物内核、名场面三项必须保住；名场面要"演"出来，不降级为过场。另列不可删信息：后文反转、能力、关系所依赖的前置信息（M5-04）。

### 改编红线
不照搬原文字句（保留情境与意象，不保留句子）；不崩内核；不丢母题；不按原著章节平铺全书。

### 小说与剧本的差异（平台在 AI 剧写作要求中明确）
小说可回翻，剧本被动接收；小说可多视角，剧本单一主视角；小说可长时间蓄力，剧本要快速兑现。

## 写完自检

正文写出后交 mj-dx-rejection，重点查"小说直转"与第 ①②④⑦⑧⑪ 项；交 mj-dx-visual 查旁白解说风险。

## 示例

### 正例一：主场景（番茄小说改编方案）
**输入**：这本番茄玄幻小说改成漫剧。
**输出**（节选）：
```
IP 改编：是；关联对应番茄 IP（M1-07）
保留：核心设定（废炉器灵）与核心情绪（被看不起后的翻身）
重构：原著前 8 章的修炼日常压成第 1 集一场冲突；男频 1-1 场就上吸睛点
删减：与主线无关的两条感情支线
```
**为什么好**：不换核心设定与核心情绪（M5-11），开场不照搬流水账（M5-01）。

### 正例二：边缘场景（自行采买的 IP）
**输入**：IP 是我自己从番茄采买的。
**输出**：上传时"是否 IP 改编"填"否"（M1-06），框架合作绑框架合同，非框架合作绑 IP 采买合同。

### 反例一：质量不足
**错误输出**：把原著段落原样贴成台词。
**问题**：混入小说原句、台词书面化，是 AI 痕迹与退稿高发项（M5-13）。

### 反例二：越界过度
**错误输出**：把男主改成女主、把炼器改成宫斗，"更好卖"。
**问题**：更换核心设定，属于魔改原著（M5-11）。

# 真人剧 · 改编（zr-cr-adapt）

目标：把原著**重新排一遍戏**，不是把文字翻译成剧本格式。平台把"小说直转"列为直接拒稿项（M5-00）。

## 五道闸（第四层通用，动笔前先过）

1. **字数闸**：真人剧每集 600 到 800 字，上限 1200（Z1-01）；千部计划每集约 375 到 500 字，40 集共 1.5 万到 2 万字（Z3-01）
2. **纯剧本闸**：投稿正文只能是纯剧本，拍摄执行类、运营标注、修改痕迹、办公备注一律不进正文（M2-08）；说明放进独立的"创作备忘"
3. **旁白闸**：不写上帝视角旁白（M4-13）；OS 依附人物，VO 写明声源（M3-07）
4. **红线闸**：按真人微短剧内容创作建议的严格避免与控量项把关（G4）
5. **依据闸**：行业数据、播放量、分账倍数不作依据；平台没写的只作经验参考并注明"非平台规则"

## 平台校准

- 必须是自有 IP 或平台授权 IP；使用平台 IP 先在「剧本创作-IP选取」申请，通过后再改（G5-01、G5-02）
- 先列不可删信息清单，建立设定与人物状态表（M5-04）
- 不按原著章节平铺，开场不写成流水账（M5-01）；不只转格式，叙述与心理不转为旁白（M5-02）
- 做减法和重排，篇幅集中到强冲突、强情绪、强转折（M5-09）
- 重构只服务戏剧化表达，不更换原著核心设定与核心情绪（M5-11）
- 剧名：头部 IP 改编完整包含 IP 名；非头部 IP 不含平台保护的作品名（G2-02）
- 以上写作标准来自平台 AI 剧写作要求，真人剧参照执行

## 工作流程

1. **权属确认**：写明 IP 来源与授权状态；未取得授权的只做方案评估，不写正文
2. 解构、守恒与不可删清单（见下）
3. **篇幅策略**：长篇原著选取戏剧密度最高的弧线深做，不 1:1 平铺；网文爽文保住爽点，把关键动作交给主角当场完成；多视角收束为单一主视角（M4-13）；长蓄力处压缩，快速兑现（M4-09）
4. **短剧友好转写**：章末钩子转集尾钩子；内心独白转动作、表情、对白；抽象场景转可拍场景；合并场景与配角，控制演员数（Z6-02）
5. **交接**：形成改编版立项卡与大纲方向，交 zr-cr-outline 排分集卡、zr-cr-opening 写开篇、zr-cr-episode 写正文

### 解构五件套
1. 母题一句话
2. 人物内核（主要角色各一句：他无论如何不会背叛什么）
3. 名场面清单 5 到 10 个，标注情绪功能
4. 情感线测绘（关系如何一步步变化）
5. 世界规则提取（不超过 5 条核心规则）

### 三大守恒与不可删清单
母题、人物内核、名场面三项必须保住；名场面要"演"出来，不降级为过场。另列不可删信息：后文反转、能力、关系所依赖的前置信息（M5-04）。

### 改编红线
不照搬原文字句（保留情境与意象，不保留句子）；不崩内核；不丢母题；不按原著章节平铺全书。

### 小说与剧本的差异（平台在 AI 剧写作要求中明确）
小说可回翻，剧本被动接收；小说可多视角，剧本单一主视角；小说可长时间蓄力，剧本要快速兑现。

## 写完自检

正文写出后交 zr-dx-rejection，重点查"小说直转"与第 ①②④⑦⑪ 项。

## 示例

### 正例一：主场景（改编方案）
**输入**：我有一本 60 万字的市井小说，想改成短剧。
**输出**（改编方案节选）：
```
保留：原著核心设定（祖传手艺之争）与核心情绪（被夺走又拿回来的扬眉吐气）
重构：原著前 5 章的成长回忆压缩成第 1 集的一个物证；第 1 场直接上夺方冲突
删减：三条与主线无关的支线人物
篇幅：60 集
```
**为什么好**：重构只为戏剧化服务，不换核心设定与核心情绪（M5-11）；开场不再照搬流水账（M5-01）。

### 正例二：边缘场景（用平台 IP）
**输入**：我想用平台 IP 库里的小说改。
**输出**：先在「剧本创作-IP选取」申请，通过后才能改编（G5-02）；改编方案同上。

### 反例一：质量不足
**错误输出**：把原著第一章的叙述句直接改成旁白："林晚从小在面馆长大，她很爱自己的父亲……"
**问题**：只转格式不做戏剧化（M5-02），对话剧不用上帝视角旁白（M4-13）。

### 反例二：越界过度
**错误输出**：为了"更爽"，把原著的手艺之争改成女主重生后开挂报复全家。
**问题**：更换了原著核心设定与核心情绪，属于魔改（M5-11）。

## 边界

- 未取得授权不写正文；不提供法律意见

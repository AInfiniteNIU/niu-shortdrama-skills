# AI漫剧 · 成片上传与上线审核诊断（mj-dx-release）

回答一个问题：**这部漫剧成片上传提审，哪里会被驳回，哪些选项填了就改不了？**

## 输入

- 成片信息：集数、时长、画幅、字幕、画风；剧名、简介、封面
- 上传计划：承诺总集数、连载或全集、是否 AI 作品、是否 IP 漫剧、合作模式
- 版权与备案材料；角色形象来源与确权材料
- 已被驳回时：驳回类别与原文（漫剧审核意见可在版权后台【作品管理】点【导出】）

## 检查清单

### A. 正片
| 项 | 标准 | 规则卡 |
|---|---|---|
| A1 | 满足漫剧定义：单集 15 分钟以下，有主线、连续情节、突出人物 | G1-01 |
| A2 | 无缺集、乱序、断更烂尾、不连贯 | G3-01 |
| A3 | 无重复；不是段子合集、多剧拼接、Vlog 或音乐视频拼接 | G3-02 |
| A4 | 画幅、音画同步、字幕齐全；无其他平台水印、引流、私下广告 | G3-02、G3-03 |
| A5 | AI 内容质量、画风一致、剧情连贯；角色不变脸 | M8-08、M9-05 |
| A6 | 成片层面的红线（模糊处理后仍可见的写实血腥、怪异扭曲形象、施暴与痛苦表情、暴露），调 mj-dx-redline | G4、M8 |

### B. 剧壳
| 项 | 标准 | 规则卡 |
|---|---|---|
| B1 | 剧名：不超过 20 字符；无书名号、尖括号、空格；标点只用逗号、感叹号、冒号、问号、双引号；不重名；IP 名规则 | G2-01 到 G2-05 |
| B2 | 简介 13 禁区与封面 10 禁区（同 mj-dx-redline 剧壳部分） | G2-07、G2-08 |
| B3 | 剧壳与正片一致，不套壳 | G2-06 |
| B4 | 改过名的要补《剧名确认书》，否则版权审核报"剧名不一致" | G1-05 |

### C. 上传选项（填了就改不了，必须先确认）
| 项 | 标准 | 规则卡 |
|---|---|---|
| C1 | 承诺总集数是整部剧的集数，不支持修改；连载上传到该集数后自动变为"已完结"并关闭上传 | M1-07 |
| C2 | "是否 AI 作品"按实际填，用了 AI 工具就选"是"，之后不能改 | M1-07 |
| C3 | IP 漫剧必须关联对应番茄 IP；自行采买的 IP"是否 IP 改编"填"否"，框架合作绑框架合同，非框架合作绑 IP 采买合同，不绑普通授权合同或 IP 参投合同 | M1-07、M1-06 |
| C4 | 抖音版本专辑 ID 创建后经营配置不可改；定时发布时间两端生效、提交后不可改；「平台发布」不能改回「自主发布」 | G1-06 |
| C5 | 自主发布账号：实名、无违规、有效粉丝 500 以上（个人不足 500 只能发免费剧）；定时发布设在 72 小时以后；连载漫剧只支持广告变现（IAA） | G1-07、M1-09 |

### D. 版权与备案
| 项 | 标准 | 规则卡 |
|---|---|---|
| D1 | 签约主体、合作剧名与材料一致；材料清晰、授权链完整 | G1-05 |
| D2 | 层级：重点（特殊题材或总投资 80 万元及以上）、普通（30 万到 80 万）、其他（不足 30 万，平台审核后报属地省级广电部门备案） | M7-01 到 M7-03 |
| D3 | 重点与普通层级上传时提供《网络剧片发行许可证》或备案号并填写对应信息 | M7-04 |

### E. 虚拟形象
| 项 | 标准 | 规则卡 |
|---|---|---|
| E1 | 基于真人形象：肖像授权文件，加肖像权人身份证核验或人脸核验；基于已有 IP：从原始权利人到使用方的完整授权链；原创：著作权登记或时间戳存证（当前非必填） | M9-01 |
| E2 | 必填：形象名称、清晰可识别的头像、10 到 100 字简介、关联剧集、形象类型 | M9-02 |
| E3 | 预检提示肖像权风险且已取得授权时，到「虚拟形象管理」提交材料确权 | M9-03 |

### F. 合作模式准入
| 项 | 标准 | 规则卡 |
|---|---|---|
| F1 | 成品普通分成：一般漫剧均可，横竖屏均可，授权 5 年起，付费为小程序充值金额 6% | M1-03 |
| F2 | 成品框架分成（首发）：只面向多角色动态交互、靠人物对话和表演推动剧情的 2D、3D 漫剧和仿真人剧，**不包含旁白解说类**；付费 7%；准入需平台数据评估 | M1-04 |
| F3 | 承制模式已暂停新增 | M1-05 |

分成与结算以合同和平台通知为准，本 skill 不做收益测算。

## 流程

1. 已被驳回：导出审核意见，按类别只查对应组，给修改顺序
2. 未上传：先逐项确认 C 组，再查 A、B、D、E、F
3. 输出报告

## 诊断纪律

- 只诊断，不代用户在平台操作；上传与确权操作交 mj-release-ops、mj-avatar
- 每条问题写位置与规则卡编号；规则卡全文见文末附录；分级必改、建议改、人工判断

## 报告格式

```
提审结论：可上传 ／ 修改后上传
不可改选项确认：承诺总集数 N；是否 AI 作品；是否 IP 漫剧及关联 IP
| # | 类别 | 位置 | 问题 | 规则卡 | 修改方向 | 级别 |
合作模式判断：普通分成 可/不可；框架分成 可/风险（理由）
通过项
交接
```

## 示例

### 正例一：主场景（上传前自查）
**输入**：漫剧明天上传，帮我查。
**输出**（节选）：
```
| 必改 | 上传选项 | 承诺总集数填 80，但剧本规划 120 集；承诺总集数不可改 | M1-07 |
| 必改 | 上传选项 | 用了 AI 工具，"是否 AI 作品"选了"否" | M1-07 |
| 提醒 | 抖音配置 | 连载漫剧只支持广告变现（IAA） | M1-09 |
| 必改 | 剧壳 | 改过剧名，未补《剧名确认书》 | G1-05 |
```
**为什么好**：先查"填了就改不了"的选项，避免上传后无法补救。

### 正例二：边缘场景（版权审核报剧名不一致）
**输入**：版权审核驳回，说剧名不一致。
**输出**：核对签约主体、合作剧名与材料；漫剧改名要补《剧名确认书》；可在版权后台【作品管理】导出审核意见对照修改（G1-05）。

### 反例一：质量不足
**错误输出**：`看着没问题，传吧。`
**问题**：没核对不可改选项、版权材料、虚拟形象确权与抖音配置。

### 反例二：越界过度
**错误输出**：建议"是否 AI 作品先选否，过审后再说"。
**问题**：该项必须如实填写且之后不能改（M1-07），这类建议有违规风险。

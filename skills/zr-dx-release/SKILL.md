# 真人剧 · 成片上线审核诊断（zr-dx-release）

回答一个问题：**这部成片提审，会在哪一类审核被驳回？**

成片审核分 6 类：正片、剧壳、版权、演员（仅真人）、别名、内容下架；驳回原因在「内容经营与管理」作品详情的审核状态里查看（G1-02）。

## 输入

- 成片信息：集数、每集时长、画幅、字幕情况；剧名、别名、简介、封面
- 版权材料：签约主体、合作剧名；备案层级与备案号（如有）
- 已被驳回时：驳回类别与原文

## 检查清单

### A. 正片
| 项 | 标准 | 规则卡 |
|---|---|---|
| A1 | 满足短剧定义：单集 15 分钟以下；具备情感价值的短故事；有明确主题和主线、连续完整的情节、突出的人物；讲述虚构或经艺术加工的事件 | G1-01 |
| A2 | 无剧名简介封面与内容不一致、剧集缺失（单集因审核下线要及时修复）、乱序、断更烂尾、剧情不连贯 | G3-01 |
| A3 | 无剧集重复或单集内剧情重复；不是段子合集、多剧拼接、Vlog 或音乐视频拼接 | G3-02 |
| A4 | 画幅正常、音画同步、字幕齐全不错乱 | G3-02 |
| A5 | 无其他平台水印或备案号；无非官方广告、引流、二维码、无关水印 | G3-02 |
| A6 | 品牌广告植入只走红果"品牌广告剧"官方流程，禁止私下植入 | G3-03 |
| A7 | 成片层面的内容红线（画面、音效、镜头角度、服饰），调 zr-dx-redline | G4 |

### B. 剧壳与别名
| 项 | 标准 | 规则卡 |
|---|---|---|
| B1 | 剧名与别名：不超过 20 字符；无书名号、尖括号、空格；标点只用逗号、感叹号、冒号、问号、双引号；不与已发布或高热预约剧名完全重复；头部 IP 完整含 IP 名，非头部不含平台保护作品名 | G2-01 到 G2-05 |
| B2 | 书名与简介避开 13 类禁区：拜金炫富；出轨婚恋观；正向表述违法犯罪；敏感话题、煽动对立、饭圈引战、造谣公众人物；各类歧视；色情低俗；夸张博眼球；【热播】【爆款】【强推】；【误传】【测试】【废弃】；罗列热剧热演员蹭热；不通顺、错别字；与剧情不一致；标点滥用 | G2-07 |
| B3 | 封面避开 10 类禁区：低俗色情；恐怖不适；非正当关系亲密互动；酗酒吸烟；非正当身份持枪；引流信息；营销字段；改编或角色信息错误；片名缺失、过小、截断或不一致；主体缺失、五官截断、抠图粗糙、马赛克、变形、模糊 | G2-08 |
| B4 | 剧壳与正片相关且一致，不套壳 | G2-06、G3-01 |

### B2. 上传资格与抖音发布配置（提交后改不了）
| 项 | 标准 | 规则卡 |
|---|---|---|
| U1 | 有上传资格：原短剧版权中心版权机构暂时可传成品真人短剧；新平台入驻的版权机构不能传；投资出品方只传撮合型真人短剧 | Z5-06 |
| U2 | 抖音版本专辑 ID 创建后经营配置不可改；定时发布时间两端生效、提交后不可改；「平台发布」不能改回「自主发布」 | G1-06 |
| U3 | 自主发布账号：实名、无违规、有效粉丝 500 以上（个人不足 500 只能发免费剧）；免费剧不支持投放；定时发布设在 72 小时以后 | G1-07 |

### C. 版权
| 项 | 标准 | 规则卡 |
|---|---|---|
| C1 | 签约主体、合作剧名与版权材料一致；报"主体不一致或剧名不一致"时逐项核对，补齐遗漏材料 | G1-05 |
| C2 | IP 改编有完整授权链；原创、自有 IP 或平台授权 IP | G5-01、G5-02 |
| C3 | 材料不模糊、不过度打码；有原始版权方证明和授权链文件 | 平台审核常见问题 |
| C4 | 工程文件：展示剪辑点和分轨的制作过程截图，不用调色配字幕阶段的工程；每张展示不同段落，建议一次给 5 到 6 张 | 平台审核常见问题 |

### D. 备案与推广
| 项 | 标准 | 规则卡 |
|---|---|---|
| D1 | 层级：重点（特殊题材或总投资 300 万及以上，广电总局统一备案和成片审查）、普通（100 万到 300 万，省级以上广电部门备案）、其他（不足 100 万，平台审核后报属地省级广电部门备案） | Z4-01 到 Z4-03 |
| D2 | 备案分两步：剧本阶段做规划备案，成片送审做上线备案；只有规划备案（G 开头 14 位）不能上线播出；已有重点备案的成片仍要走平台审核 | 果燃计划合作手册 |
| D3 | 果燃精品推广：必须已有微短剧上线备案号、版权清晰、仅限竖屏 | Z5-02 |

### E. 审核流程
- 通常 24 小时内完成，按提审时间排队，不能催审；抖音版本链路更长，定时发布时间到了仍可能在审核中（G1-03）
- 正片不通过但单集都通过且没有修改建议时，直接联系客服（G1-04）
- 审核结果在右上角消息中心「审核状态变更」查看；下架看「上下架通知」

## 流程

1. 已被驳回：先定位驳回类别，只查对应组，给出修改顺序
2. 未提审：A 到 D 逐项自查
3. 输出报告，按审核类别分组

## 诊断纪律

- 只诊断，不代用户在平台操作；平台操作步骤交 zr-release-ops
- 每条问题写位置（集、时间点或物料）与规则卡编号；规则卡全文见文末附录
- 分级：必改、建议改、人工判断；涉及备案程序以主管部门和平台通知为准

## 报告格式

```
提审结论：可提审 ／ 修改后提审
按审核类别：正片 / 剧壳 / 版权 / 演员 / 别名 / 备案
| # | 类别 | 位置 | 问题 | 规则卡 | 修改方向 | 级别 |
通过项
交接
```

## 示例

### 正例一：主场景（提审前自查）
**输入**：明天上传，帮我查一遍。
**输出**（节选）：
```
| 必改 | 剧名 | 21 个字符，超过 20 | G2-04 |
| 必改 | 抖音配置 | 计划定时发布在明早 9 点，不足 72 小时 | G1-07 |
| 提醒 | 抖音配置 | 专辑 ID 创建后经营配置不可改，提交前再核一遍付费卡点 | G1-06 |
| 通过 | 备案 | 普通微短剧，已有省级备案号 | Z4-02 |
```
**为什么好**：把"提交后改不了"的项单独标出来，先于其他项处理。

### 正例二：边缘场景（新入驻版权机构）
**输入**：我们公司刚在新平台入驻版权机构，想上传成品真人短剧。
**输出**：新平台入驻的版权机构不支持上传成品真人短剧（Z5-06）；如是撮合项目，需以投资出品方身份上传；否则先联系对接商务确认合作方式。

### 反例一：质量不足
**错误输出**：`材料齐了就能过。`
**问题**：没有逐项核对剧壳、版权、备案与发布配置。

### 反例二：越界过度
**错误输出**：教用户把重点微短剧的总投资报低一点，按"其他微短剧"走平台自审。
**问题**：规避备案层级是违规建议，诊断必须按实际题材与投资判断层级（Z4-01 到 Z4-03）。

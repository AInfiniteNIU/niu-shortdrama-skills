# AI漫剧 · 可生成性与一致性诊断（mj-dx-visual）

回答一个问题：**这份剧本交给 AI 生产，画不画得出来、画得稳不稳、合作模式受不受影响？**

## 输入

- 剧本正文（全集或待查集数）
- 主要角色的形象设定（文字或图片）；形象来源说明（原创、基于真人、基于已有 IP）
- 计划的合作模式（成品普通分成、成品框架分成）

## 检查清单

### A. 动作行可画性
| 项 | 标准 | 规则卡 |
|---|---|---|
| A1 | 每条动作行写的是可见的动作、表情、画面，不写"心里五味杂陈"之类抽象评价 | M3-04 |
| A2 | 一行一个连续动作单元；多人同场时每行能判断由谁完成 | M3-04 |
| A3 | 大场面落到可见细节：谁先动、哪件东西先碎、旁人什么反应；不是只有"天地变色、万军对峙" | M5-03 |
| A4 | 心理活动外化为动作和表情，不用大段 OS | M5-02、M4-04 |
| A5 | 首次出场写清外貌、服装、状态、身份，足够作为生成依据 | M3-05 |

### B. 叙事方式与合作模式
| 项 | 标准 | 规则卡 |
|---|---|---|
| B1 | 统计每集叙述性旁白、无主 OS、VO 的处数；对话剧不用上帝视角旁白 | M4-13、M5-08 |
| B2 | 框架分成合作只收"多角色动态交互、靠对话和表演推动剧情"的作品，不收旁白解说类；判断本剧是否会被归为旁白解说类 | M1-04 |
| B3 | 纯 NPC 对话缺画面、纯画面缺对话，都是 AI 跑稿痕迹 | M5-13 |
| B4 | 单一主视角，不靠切换视角解说 | M4-13 |

判定口径：一集中主要信息靠旁白或解说交代、人物对话只作点缀，即视为旁白解说类风险。计划走框架合作的列为"必改"，只走普通分成的列为"建议改"。

### C. 一致性
| 项 | 标准 | 规则卡 |
|---|---|---|
| C1 | 主要角色的外形描述在各集首次出场、换装、受伤、变身前后是否一致；建议用户维护形象锚点卡（年龄感、脸型、发型发色、瞳色、常穿服装、标志物、表情组） | M8-08、M9-05 |
| C2 | 画风、色调、世界观视觉元素是否全剧一致 | M8-08 |
| C3 | 设定、能力、伤势、关系的前后一致（与 mj-dx-rejection 第 ④ 项联动） | M5-04 |

### D. 形象权属
| 项 | 标准 | 规则卡 |
|---|---|---|
| D1 | 形象基于真人：需要肖像授权文件，并由肖像权人通过证件或人脸核验 | M9-01 |
| D2 | 形象基于已有 IP：需要从原始权利人到使用方的完整授权链 | M9-01 |
| D3 | 原创形象：著作权登记或时间戳存证当前非必填，建议准备 | M9-01 |
| D4 | 剧本对角色外形的描述若明显指向某位真实公众人物，提示肖像权与红线风险 | M9-03、G4-09 |

### E. 视觉奇观与红线
| 项 | 标准 | 规则卡 |
|---|---|---|
| E1 | 奇观（觉醒、天地异象、超现实空间、战斗特效）是否服务剧情，而非堆砌 | M5-03 |
| E2 | 奇观是否依赖写实血腥、断肢、怪异扭曲形象、阴森恐怖画风取胜 | G4-07、M8-04、M8-05 |
| E3 | 角色造型与服装是否存在暴露、擦边 | G4-08 |

## 流程

1. 抽查首集、第 10 集、第 30 集（或全集）逐行看动作行，标出不可画或主语不明的行
2. 统计每集旁白、OS、VO 处数，判断旁白解说类风险
3. 建角色外形对照表，逐集核对首次出场与变化节点
4. 判断形象来源与确权材料
5. 检查奇观段落的红线风险
6. 输出报告

## 诊断纪律（第三层通用）

- **只诊断，不写稿**：可以给一句修改方向或一行示意，不重写段落；改稿交给第四层（mj-cr-episode、mj-cr-character、mj-cr-handoff、mj-cr-revise）
- **每条问题都要有出处**：位置（第几集第几场或第几行）、规则卡编号、原文要点
- **分级**：
  - 必改：违反【硬】规则，不改会退稿、驳回或无法上线
  - 建议改：违反【控】规则或【荐】写法，影响评级或过稿率
  - 人工判断：关键词或情节存在风险，需要结合上下文确认
- **不凭经验加规则**：规则卡没有的标准不作为扣分依据，可在"补充意见"里单列并注明"非平台规则"
- **时效**：引用有截止日期的规则（如千部计划 2026-12-31）时，先对照当前日期

## 报告格式（固定）

```
诊断结论：可投 ／ 需改后投 ／ 不建议投
一句话理由：……

一、必改（共 N 条）
| # | 位置 | 问题 | 规则卡 | 修改方向 |

二、建议改（共 N 条）
| # | 位置 | 问题 | 规则卡 | 修改方向 |

三、人工判断（共 N 条）
| # | 位置 | 风险 | 规则卡 | 判断要点 |

四、通过项
- 逐项列出已检查且合格的项目

五、交接
- 交给哪个第四层 skill 改，按什么顺序改
```

结论判定：有任何一条"必改"即不能判"可投"；必改项集中在价值观红线或"小说直转、AI 直出"时判"不建议投"。

## 示例

### 正例一：主场景（可生成性诊断）
**输入**：这个剧本 AI 画得出来吗？
**输出**（节选）：
```
| 必改 | 3-1 第 4 行 | "他心中涌起无限悲凉"无法生成画面 | M3-04 |
| 必改 | 第 7 集 | 沈烬眉疤从右眉变成左眉，与形象锚点不一致 | M9-05、M8-08 |
| 建议改 | 第 12 集 | 大比场面只写"人山人海"，缺可见细节 | M5-03 |
```
**为什么好**：逐行检查可画性与一致性，问题落到可执行的修改。

### 正例二：边缘场景（形象像某个明星）
**输入**：女主画得很像某女星，有问题吗？
**输出**：外形明显指向真实公众人物且未取得授权，有肖像权风险（G4-09）；取得授权的需走"基于真人形象改编"确权（M9-01，办理见 mj-avatar），否则建议调整五官特征。

### 反例一：质量不足
**错误输出**：`画面感还行。`
**问题**：没有逐场检查动作行，也没核对角色一致性。

### 反例二：越界过度
**错误输出**：直接替用户重写了全部动作行并生成了分镜。
**问题**：诊断不写稿；改写交 mj-cr-revise，分镜交 mj-cr-handoff。

## 边界

- 不生成图片、不写视频提示词；生产文件交给 mj-cr-handoff 和用户已有的分镜、视频 skill
- 确权的平台操作步骤交给 mj-avatar

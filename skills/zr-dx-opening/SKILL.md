# 真人剧 · 开篇诊断（zr-dx-opening）

回答一个问题：**第 1 集能不能留住人，前 3 集能不能让人追下去？**

平台没有单独的真人剧写作标准，本 skill 采用平台《AI剧长篇剧本创作要求》中的首集与前 3 集标准，真人剧参照执行，报告中注明；字数按真人剧口径（Z1-01）。

## 输入

- 第 1 到 3 集正文（必需）；立项卡或一句话主线、男女频、目标用户（有更好）

## 检查清单

### A. 首集开场（必改级）
| 项 | 标准 | 规则卡 |
|---|---|---|
| A1 | 男频 1-1 场出现吸睛点；女频第 1 集内明确核心冲突、危机、暧昧、反差或悬念；前 10 秒留不住人会被划走 | M4-01 |
| A2 | 无大段难懂长句；无超过 20 秒的世界观解释；无寒暄；不只铺家庭背景 | M4-02 |
| A3 | 看完第 1 集能回答：主角被什么压迫、失去了什么、急需解决什么、接下来要解决什么 | M4-03 |
| A4 | 冲突、危机或金手指没有拖到第 2 到 5 集才出现；开篇不是身世、环境、寒暄 | M5-01 |
| A5 | 不用旁白起手，不用叙述句交代心理 | M4-13、M5-02 |

### B. 首集信息密度
| 项 | 标准 | 规则卡 |
|---|---|---|
| B1 | 每场至少一个功能：推主线、揭关系、造冲突、立人设 | M4-04 |
| B2 | 不重复解释；对白不能只表态不产生变化 | M4-04 |
| B3 | 不用心理描写代替行动 | M4-04 |
| B4 | 首集字数 600 到 800，不超过 1200 | Z1-01 |

### C. 前 3 集
| 项 | 标准 | 规则卡 |
|---|---|---|
| C1 | 一句话讲清主线：主角是谁、处境、目标；目标有明确对象与阶段性动作，不是"我要变强""我要复仇"之类空话；能长线 | M4-05 |
| C2 | 世界观或人物关系用事件演出，不罗列；该交代的已交代 | M4-06、M5-07 |
| C3 | 目标用户明确；男频给获得感或新奇体验，女频建立关系感或人物吸引力 | M4-07 |
| C4 | 悬念、冲突、反转有因果；关键选择让观众知道动机；无小因大果、强行反转、强行降智 | M4-08 |
| C5 | 前 5 集至少 1 个钩子，检查前 3 集是否已立住 | M4-14 |

### D. 经验参考（非平台规则，列入补充意见）
- 第一行属于哪种起手：冲突爆裂、悬念炸弹、承接引爆、视觉冲击、认知颠覆；若是环境描写或日常动作，提示
- 开场 10 秒内（平台标准：前 10 秒留不住人就会被划走）是否建立敌我、利益、危机量级
- 是否有"被欺负、反击、对方震惊、更大对手露面"的迷你闭环

## 流程

1. 逐场建"功能表"：场次、出场人物、本场功能、本场新信息、是否有冲突
2. 对照 A、B、C 判定
3. 用一句话复述主线；复述不出来即 C1 不通过
4. 输出报告，并给出"最该先改的一处"

## 诊断纪律（第三层通用）

- 只诊断不写稿：给修改方向，不重写段落；改稿交给第四层（zr-cr-opening）
- 每条问题写位置（集、场、行）、规则卡编号、原文要点；规则卡全文见文末附录
- 分级：必改（违反【硬】规则，不改会退稿、驳回或无法上线）、建议改（违反【控】或【荐】，影响评级或过稿率）、人工判断（需结合上下文确认）
- 规则卡以外的意见单列为"补充意见（非平台规则）"
- 结论判定：有任何一条必改即不能判"可投"

## 报告格式

```
诊断结论：可投 ／ 需改后投 ／ 不建议投
一句话理由：
逐场功能表：| 场次 | 功能 | 新信息 | 冲突 |
一、必改  二、建议改  三、人工判断
| # | 位置 | 问题 | 规则卡 | 修改方向 |
四、通过项
五、补充意见（非平台规则）
六、交接：zr-cr-opening
```

## 示例

### 正例一：主场景（逐场功能表）
**输入**：第一集能留住人吗？
**输出**（节选）：
```
| 场次 | 功能 | 前 10 秒 | 问题 |
| 1-1 | 夺方冲突 | 有：文件拍在柜台上 | 无 |
| 1-2 | 回忆父亲 | 无冲突 | 建议删或压成一个物证 |
结论：首场合格，第二场拖慢节奏（M4-02）
```
**为什么好**：逐场看功能，用平台"前 10 秒"标准判断。

### 正例二：边缘场景（只给了前三集大纲）
**输入**：正文还没写，只有前三集大纲。
**输出**：先按大纲诊断前 3 集任务是否完成（M4-05：主线一句话能否讲清），正文格式项标"待正文后复查"。

### 反例一：质量不足
**错误输出**：`开头挺吸引人的。`
**问题**：没有逐场与标准对照。

### 反例二：越界过度
**错误输出**：直接把第一集重写了一版交给用户。
**问题**：诊断不写稿，重写交 zr-cr-opening。

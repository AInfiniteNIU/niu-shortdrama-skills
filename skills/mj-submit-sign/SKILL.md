# AI漫剧 · 合作、IP 与签约（mj-submit-sign）

## 办事纪律（第二层通用）

- 本 skill 已内置办理所需的平台规则与操作路径（整理自短剧创作者中心帮助中心，截至 2026-11），使用时无需另查文档
- 只告诉用户怎么办、在哪里办、时限和坑；不替用户登录、填表、付款或输入证件号
- 路径与按钮名称以内置内容为准，界面以平台当前版本为准；遇到内置内容未覆盖的情况，联系平台页面右下角【客服中心】或对接商务
- 不可逆的操作（实名、身份选择、完结申请、上传时的不可改选项、账号注销）先提醒后果
- 分成、单价、额度以最终协议和站内信为准；标"待核"的事项先通过客服或商务确认再动手

## 一、三种合作模式（国内）

| 模式 | 对象 | 授权 | 付费分成 | 准入 |
|---|---|---|---|---|
| 一：成品普通分成 | 对公机构、个人达人 | 普通授权，授权期 5 年，分成期 5 年起，全球 | 免费为普通单价；付费为付费小程序充值金额 6% | 有制作完整成片的能力；权属清晰不侵权；一般漫剧均可；横竖屏均可 |
| 二：成品框架分成（免费加付费首发） | 对公机构、个人达人 | 特定授权，授权期 1 年，分成期永久，全球 | 免费为特定单价；付费 7% | 符合平台数据评估标准后，商务主动建联或站内信推送；**仅面向多角色动态交互、靠人物对话和表演推动剧情的 2D、3D 漫剧和仿真人剧，不包含旁白解说类** |
| 三：承制 | 对公机构 | 仅承制 | 特定单价，全渠道免付费净收益 70% 分账 | **已暂停新增**（原要求月提交不少于 1 部、单部完结时长达 120 分钟、不含旁白解说类） |

海外承制与海外剧本征稿当前暂停。想走模式二的，先让作品过 mj-dx-visual 的旁白解说风险检查。

## 二、签约

1. 先完成入驻认证（mj-onboard）；在原短剧版权中心签过合同的可跳过
2. 合作咨询：登录后点右下角【客服中心】；模式二由平台评估后主动开放
3. 【消息中心】→【任务通知】→【合同管理】→ 选漫剧 →【待申请】→【申请合同】；如提示需签约认证，按"填写主体资质、对公验证、校验认证信息、提交"完成
4. **申请时填写的企业信息、签约人信息、银行信息提交后不可修改**；合同生成一般 3 个工作日；在【待签约】点【前往签约】
5. **合同按模式签，不按剧签**：模式二主合同是框架空合同，IP 名与作者可填"/"；在后台 IP 库成功申请 IP 后自动下发补充协议作为授权证明，无需签署
6. 绑定：【合同管理 - 漫剧】→【生效中】→ 目标合同右侧【绑定漫剧】→ 勾选漫剧

## 三、IP 申请与采买

- 获得模式二后自动开通 IP 库权限；平台按合作情况定期调整每月可改编的 IP 数量
- 超出额度：通过番茄原创版权商务自行采买
- **自行采买 IP 的上传填法**："是否 IP 改编"填【否】；框架合作则绑框架合同；非框架合作绑与番茄原创签的 IP 采买合同，不要绑普通授权合同或 IP 参投合同
- 用平台 IP 制作的漫剧，上传时严格关联对应的番茄 IP（M1-07）

## 四、AI 剧剧本投稿（编剧侧）

- 剧本按投稿模板 13 项附件准备（可用 mj-dx-package 自检）：剧本名称；是否 IP 改编；IP 小说名加 IP 编号；男女频；世界观；主分类；预计创作集数；一卡集数加推荐说明；推荐首发剧情卡点（仅连载）；简介 150 到 500 字；大纲每 10 集一段写全；主要人设每人 50 到 100 字；剧本正文
- AI 剧编剧投稿已有投稿标准（平台 2026-11 发布 AI 剧投稿模板与长篇创作要求），投稿入口以站内为准；签约方式以站内信与客服答复为准
- 真人剧保底表是否适用于 AI 漫剧剧本，以签约站内信为准（G5-09，待核）
- 平台提醒：投稿数量不会产生过稿机会，只会产生退稿记录

## 五、其他渠道

- 客服：右下角【客服中心】，09:00 到 19:00，可咨询后台操作、功能指引、漫剧催审
- 侵权投诉、到期或纠纷下架：发红果短剧举报邮箱（平台公开地址 hongguojubao@bytedance.com），附权利人主体信息、权利证明、侵权初步证据；3 个工作日内回复（不含双休日与法定节假日）
- 品牌广告植入只能走红果品牌广告剧官方流程（G3-03）

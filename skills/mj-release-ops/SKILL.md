# AI漫剧 · 成片上传与经营（mj-release-ops）

## 办事纪律（第二层通用）

- 本 skill 已内置办理所需的平台规则与操作路径（整理自短剧创作者中心帮助中心，截至 2026-11），使用时无需另查文档
- 只告诉用户怎么办、在哪里办、时限和坑；不替用户登录、填表、付款或输入证件号
- 路径与按钮名称以内置内容为准，界面以平台当前版本为准；遇到内置内容未覆盖的情况，联系平台页面右下角【客服中心】或对接商务
- 不可逆的操作（实名、身份选择、完结申请、上传时的不可改选项、账号注销）先提醒后果
- 提审前建议先跑 mj-dx-release 与 mj-dx-redline

## 一、上传前确认（填了就改不了）

| 选项 | 规则 |
|---|---|
| 承诺总集数 | 是整部剧的集数，不支持修改；连载中的漫剧上传到该集数后自动变为"已完结"，上传入口关闭 |
| 是否 AI 作品 | 使用 AI 工具制作就选"是"，后续不支持修改 |
| 是否 IP 改编 | 平台 IP 库申请的：选"是"并严格关联对应番茄 IP；自行采买的：选"否"，框架合作绑框架合同，非框架合作绑 IP 采买合同 |

## 二、上传步骤

1. 先签合同（mj-submit-sign）；【合同管理 - 漫剧】→【生效中】→【绑定漫剧】
2. 「内容管理与经营-漫剧」→「上传漫剧」
3. 填剧壳信息、基础信息、制作团队（用于备案，不在 App 展示；无团队填个人信息）、角色备案信息（角色名不明确可填身份设定）、合同信息、版权信息（按漫剧权利材料要求提交，IP 授权补充协议会陆续推送）
4. 上传视频，可拖拽调序；视频编辑按钮可改抖音端发布信息
5. 属于重点或普通层级的（特殊题材，或总投资 30 万元及以上；80 万元及以上为重点），提供《网络剧片发行许可证》或备案号并填写对应信息
6. 角色形象涉及真人肖像或已有 IP 的，先做形象确权（mj-avatar）

## 三、审核与驳回

- 类别：正片、剧壳、版权、别名、内容下架（演员审核仅真人剧）
- 看结果：消息中心「审核状态变更」「上下架通知」；看原因：「内容经营与管理」→「漫剧」→ 作品 →「查看详情」
- 导出审核意见：版权后台【作品管理】→【导出】得剧壳审核意见；【查看正文】→【导出】得作品审核意见，可对照修改
- 时效：通常 24 小时内，按提审顺序，不能催审；抖音版链路更长

| 常见驳回 | 处理 |
|---|---|
| 主体或剧名不一致 | 核对签约主体、合作剧名与材料；**改过名的补《剧名确认书》** |
| 材料模糊或权属缺失 | 补原始权利方证明与授权链，去掉过度打码 |
| 工程文件不合格 | 给能看到剪辑点和分轨的制作过程截图，各张不同段落，建议 5 到 6 张 |
| 被认定非漫剧 | 单集 15 分钟以下，有主线与连续情节；不是段子合集、多剧拼接、Vlog 或音乐视频拼接 |
| 正片不通过但单集都通过且无建议 | 联系客服 |

## 四、管理与经营

- 版本生成前「编辑信息」；生成后在「红果版本」或「抖音版本」→「版本编辑」
- 抖音原生经营：「发布账号」「经营配置」「投放管理」；"单集+全集付费"支持付费点播与广告营销投放，"全集付费"只支持广告营销
- 发布抖音号：机构账户最多绑定 200 个
- **提交前确认，提交后改不了**（G1-06）：抖音版本专辑 ID 创建成功后，发布账号、经营模式、付费开关、付费面板与卡点、广告营销开始时间、会员付费开启时间都不能再改；定时发布时间同时作用于红果和抖音两端，提交后不可改；选了「平台发布」不能再改回「自主发布」
- 自主发布账号条件（G1-07）：抖音实名、状态正常无违规处罚、有效粉丝 500 以上（个人账号不足 500 只能发免费剧）；免费剧不支持投放；定时发布只能设在 72 小时以后
- 漫剧特有（M1-09）：连载漫剧只支持广告变现（IAA）；约定模式下付费开关打开时，广告营销只能选择发布后立即开启
- 品牌广告植入只走官方流程

## 五、侵权、下架与客服

- 侵权投诉、到期或纠纷下架：发红果短剧举报邮箱（平台公开地址 hongguojubao@bytedance.com），3 个工作日内回复（不含双休日与法定节假日）
- 客服：右下角【客服中心】，09:00 到 19:00，可咨询漫剧催审

## 交接

提审前自查转 mj-dx-release；形象确权转 mj-avatar；结算与数据转 mj-settle-data。

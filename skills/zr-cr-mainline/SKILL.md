# 真人剧 · 主线与设定（zr-cr-mainline）

目标：给全剧一条**一句话说得清、撑得起完稿集数、观众前 3 集就懂**的主线，和一套不罗列、可拍的设定。

## 五道闸（第四层通用，动笔前先过）

1. **字数闸**：真人剧每集 600 到 800 字，上限 1200（Z1-01）；千部计划每集约 375 到 500 字，40 集共 1.5 万到 2 万字（Z3-01）
2. **纯剧本闸**：投稿正文只能是纯剧本，拍摄执行类、运营标注、修改痕迹、办公备注一律不进正文（M2-08）；说明放进独立的"创作备忘"
3. **旁白闸**：不写上帝视角旁白（M4-13）；OS 依附人物，VO 写明声源（M3-07）
4. **红线闸**：按真人微短剧内容创作建议的严格避免与控量项把关（G4）
5. **依据闸**：行业数据、播放量、分账倍数不作依据；平台没写的只作经验参考并注明"非平台规则"

## 平台校准（真人剧参照平台 AI 剧写作标准执行）

- 前 3 集一句话讲清主线：主角是谁、当前处境、要完成什么目标；目标有明确对象与阶段性动作，不是"我要变强""我要复仇"的空话；不能短期可解决（M4-05）
- 简单设定第 1 集交代清，复杂的前 3 集；用事件演出，不罗列（M4-06）
- 复杂设定要精炼，不能一刀删到后文看不懂（M5-07）
- 篇幅：千部计划 40 集，中短篇不少于 60 集，长篇不少于 80 集（Z1-03）
- 可拍：设定合理，避免大量特效依赖（Z6-02）
- 现代背景的投胎转世、灵魂附身、阴曹地府、术法控量；正面人物不鼓吹迷信、不借法术作恶（G4-06、G4-11）
- 主要剧情涉及政治、军事、外交、国家安全、统战、民族、宗教、司法、公安即进入重点备案（Z4-04）
- 不影射负面社会热点，不贬损恶搞真实公众人物与真实企业（G4-09）

## 方法

1. **一句话主线**：用"谁，在什么处境下，要对谁做成什么，第一步是什么"写成一句。写不出"第一步"就是空话
2. **长线发动机**：矛盾按个人、家族、社会或命运三层升级，每层换一个对手；现实题材可用"家庭、公司、行业"三层。社会层的对手是具体的人与利益团体，不写成阶层对立（G4-04）
3. **真相钩子**：一个贯穿全剧的终极秘密，开局抛出，每个阶段露一角
4. **增长曲线**：第二、第三阶段各引入更大的局面（更高层级、更大利益、更深秘密），避免中后段重复
5. **设定极简**（古装、玄幻、脑洞）：三句话说清，一个场景感受到；不超过 5 条核心规则；设计一个记忆锚点（一件物、一个规矩、一句口号）
6. **规则演出来**：每条核心规则配一个首次出现的事件，标明在哪一集
7. **现实题材可信度**：职业、行业、年代细节列 3 到 5 个可见的真实细节（物件、流程、口头语），用来写动作行和台词

## 交付：主线书（创作备忘）

```
一句话主线：
长线发动机：第一层 / 第二层 / 第三层（各自对手与大致集数）
真相钩子：秘密 / 抛出集 / 露角集 / 揭开集
增长曲线：
核心规则（不超过 5 条）：| 规则 | 首次演出事件 | 集 |
记忆锚点：
现实细节清单：
可拍性提示：需要特效的设定及替代写法
红线与备案提示：
```

## 写完自检

交 zr-dx-opening 查前 3 集的主线与设定交代；交 zr-dx-buyer 查可拍性。

## 示例

### 正例一：主场景（核心冲突梳理）
**输入**：主线帮我理一理。
**输出**：
```
主线一句话：林晚要在三个月内让面馆重新挂牌，证明卤方属于林家
核心冲突：林晚（手艺与老街口碑）对周倩（文件、资金与品牌渠道）
长线发动机：个人（夺回署名）→ 家族（让母亲和舅舅和解）→ 老街（面馆成为老街改造的保留招牌）
阶段目标：第 1 到 10 集被夺方与反击立威；11 到 25 集比赛与资方介入；26 到 35 集真相与代价；36 到 40 集清算与团圆
```
**为什么好**：一句话讲清主角、处境、目标与对手（M4-05），三层升级让 40 集撑得住。

### 正例二：边缘场景（设定复杂要精炼）
**输入**：我有一大堆卤方的历史设定，全塞进去吗？
**输出**：列"不可删信息"三条（卤方来源、署名公证时间、父亲留下的手写本），其余设定用事件演出，不在台词里讲解（M5-07）。

### 反例一：质量不足
**错误输出**：`主线：女主一路打脸，最后成功。`
**问题**：没有具体目标、对手手段和阶段，后面一定注水。**改法**：写清"要什么、谁挡着、靠什么赢、代价是什么"。

### 反例二：越界过度
**错误输出**：把主线改成林晚靠风水改运、借鬼神之力让对手破产。
**问题**：现代背景下正面人物借玄学成事，属于封建迷信红线（G4）。**改法**：转折靠证据、手艺和规则。

## 边界

- 不写分集（交 zr-cr-outline）；题材本身不成立时回 zr-cr-topic

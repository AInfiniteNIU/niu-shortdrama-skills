# 短剧创作者中心 skill 系统

两套系统共 50 个 skill：真人剧（zhenren-hub 与 zr 系列）、AI漫剧（manju-hub 与 mj 系列）。每个 skill 都已内置所需的平台规则全文（整理自短剧创作者中心帮助中心，截至 2026-11），可独立安装、独立使用，不依赖平台官方文档。

## 安装

把需要的 skill 文件夹整个放进你的 skills 目录（每个文件夹含 SKILL.md，部分含 scripts/check_script.py 机检脚本）。建议同时安装对应系统的 hub，便于路由。

## 四层分工

- 第一层 路由：规则问答与需求分发，内置完整规则卡库与 20 条冲突裁决
- 第二层 办事：平台上怎么操作
- 第三层 诊断：只诊断不写稿
- 第四层 创作：写剧本，交付纯剧本，写完交第三层自检

## 编号说明

正文中的 G（两套共用）、Z（真人剧）、M（AI漫剧）编号是规则卡索引，每个 skill 文末附录给出所引用规则卡的全文；X 编号为冲突裁决，见两个 hub。

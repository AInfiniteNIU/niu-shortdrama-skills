# AI漫剧 · 开篇与首集（mj-cr-opening）

目标：观众被动接收、不会回看（M1-02），前 10 秒留不住就被划走（M4-01）。第 1 集要抓住人，前 3 集要让人追。

## 五道闸（第四层通用，动笔前先过）

1. **字数闸**：单集 1 到 2 分钟体量，全剧平均约每集 1000 字以满足 7 万字下限（M1-01、M1-02）
2. **纯剧本闸**：正文零运营标注、零分镜、零提示词（M2-08）
3. **旁白闸**：不写叙述旁白、不用第一人称解说开场（M1-04、M4-13）；系统音、广播用 VO 并写明声源
4. **红线闸**：开场奇观不靠写实血腥、扭曲恐怖、暴露取胜（G4-07、G4-08、M8-04、M8-05）
5. **依据闸**：平台没写的写法只作经验参考

## 输入

- 立项卡、人设与形象锚点、世界观要点；大纲或前 10 集分集卡（有更好）
- 男频还是女频（决定吸睛点位置）

## 平台硬标准

| 项 | 标准 | 规则卡 |
|---|---|---|
| 吸睛点 | 男频 1-1 场就出现；女频第 1 集内明确核心冲突、危机、暧昧、反差或悬念 | M4-01 |
| 禁止 | 大段难懂长句；超过 20 秒专门解释世界观；寒暄；只铺背景无冲突 | M4-02 |
| 处境代入 | 第 1 集看完知道主角被什么压迫、失去什么、急需解决什么 | M4-03 |
| 信息密度 | 每场有功能；不重复解释；不用心理描写代替行动 | M4-04 |
| 世界观 | 简单的第 1 集交代清，复杂的前 3 集交代清；靠事件演出，不罗列等级势力谱系 | M4-06、M5-07 |
| 目标用户 | 男频前 3 集给获得感、升级感或新奇体验；女频前 3 集建立关系感、CP 感或人物吸引力 | M4-07 |

## 方法

1. **第一行即利剑**（五选一）：冲突爆裂、悬念炸弹、承接引爆、视觉冲击、认知颠覆。漫剧首个画面可用视觉奇观或极端冲突破题，但奇观要服务处境，不为炫技
2. **三种黄金开场**：高潮前置（闪回交代起止）、突发事件、认知冲突
3. **信息炸弹**：开场 10 秒内（平台标准：前 10 秒留不住人就会被划走），用对抗性对白和行为植入敌我、利益、危机量级、情绪锚点；世界规则用一个具体事件演出，不由任何人讲解
4. **开场迷你闭环**：被欺负、反击、对方震惊、更大对手露面
5. **首集清单**：3 秒冲突或悬念；10 秒内敌我与处境；主角靠行为立人设；引出核心人物与矛盾；金手指第一丝暗示；结尾非看第二集不可
6. **前三集分工**：第 1 集憋屈与处境；第 2 集第一次情绪爆破；第 3 集锁定核心钩子，主线一句话可讲清（M4-05）。男频的金手指或觉醒通常在前 3 集内兑现第一次；女频的关系张力在第 1 集就要立起来
7. **可画与外化**：动作行写可见的动作、表情、画面，不写"心中十分不甘"；心理用动作、表情、简短 OS 外化；情感视觉化写进动作行（压抑用冷色雨雾，觉醒用暖金光柱）；首次出场的【字幕】与动作行把外貌、服装、状态写足，与形象锚点卡一致

## 正文格式（平台《AI剧自制编剧投稿模板》）

集标题"第一集"；场次"1-1 地点 时间 内外"；"出场人物："行（中文逗号，末尾无句号）；【字幕：姓名/身份】；△动作行；"人物（语气）：台词"；OS 依附人物，VO 写明声源；集尾"（本集完）"。

## 示范写法（第一集开头，男频玄幻）

```
第一集

1-1 青云宗演武台 日 外
出场人物：陆沉，执事长老，赵元度，众弟子

【字幕：陆沉/青云宗外门弟子】
△陆沉穿洗到发白的灰袍，双掌按在一人高的测灵石上。
△测灵石一片灰暗，连一丝光都没有亮。
执事长老（冷淡）：灵根全废。按宗规，今日逐出山门。
△台下哄笑。赵元度抱着手臂走上台。
【字幕：赵元度/内门首席】
赵元度（笑）：三年前你抢走的筑基丹，宗门该收回了吧？
△陆沉没有看他，盯着测灵石底部一道细如发丝的裂纹。
△裂纹里渗出一缕金光，顺着他的指尖爬上手腕。
陆沉（OS）：这道纹，三年前就在。
△金光一闪即灭。赵元度的笑僵在脸上，他看见了。
```

这段在 1-1 场完成了吸睛点（被逐出山门）、对手（赵元度）、金手指暗示（金光）、下一个冲突（对手也看见了），没有旁白，世界观只用"测灵石"和"宗规"两个事件交代。

## 交付

1. **正文**：第 1 到 3 集纯剧本
2. **创作备忘**（另起）：每集字数；吸睛点位置；首集清单对照；世界观交代了哪几条、靠哪个事件；视觉奇观清单；伏笔与预计回收集数

## 写完自检

运行本 skill 目录 scripts/check_script.py（`--mode mj`）查格式；交 mj-dx-opening 查首集与前 3 集；交 mj-dx-visual 查可画性与旁白解说风险。定点回改，最多两轮。

## 示例

### 正例一：主场景（第一集开场片段）
**输入**：写第一集开场。
**输出**（片段）：
```
第一集

1-1 青云宗杂役峰炉房 夜 内
出场人物：沈烬，赵玄
△赵玄一脚踢翻沈烬面前的废炉，炉灰扬了一地。
赵玄（冷笑）：烧了三年炉，连块铁都炼不出来。明日起，你滚下山。
△沈烬弯腰去扶炉，左手腕的铁链碰到炉壁，炉膛里亮起一点金光。
【VO】器灵（低沉）：三年了，总算有人把手伸进来。
△沈烬猛地抬头，炉房里只有他一个人。
```
**为什么好**：男频 1-1 场就有吸睛点（M4-01）；10 秒内敌我、处境、金手指暗示全部到位；VO 写明声源（M3-07）。

### 正例二：边缘场景（女频漫剧）
**输入**：女频古风漫剧，第一集怎么起？
**输出**：女频要求第 1 集内明确核心冲突、危机、暧昧、反差或悬念（M4-01）：可以让女主在被退婚的当场，接住一份只有她看得懂的密信，危机和悬念同时成立。

### 反例一：质量不足
**错误输出**：
```
【旁白】很久很久以前，天地间有九大宗门，青云宗位列第七……
```
**问题**：开场用旁白讲世界观，超过 20 秒没有冲突（M4-02、M4-13）。

### 反例二：越界过度
**错误输出**：开场写"【视觉奇观】血雨漫天，尸横遍野"，并标"爽点：开局虐杀"。
**问题**：写实血腥属于红线（M8-04）；正文不能有创作标注（M2-08）。

## 边界

- 不写分镜和提示词（交 mj-cr-handoff）
- 不改全剧主线；主线问题回 mj-cr-topic 或 mj-cr-outline

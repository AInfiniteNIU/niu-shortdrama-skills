# 真人剧 · 选题与立项（zr-cr-topic）

目标：做出一个**平台收、资方愿意拍、观众三秒能看懂**的选题，并把它压成一张立项卡，交给大纲和人物环节。

## 五道闸（第四层通用，动笔前先过）

1. **字数闸**：真人剧每集 600 到 800 字，上限 1200（Z1-01）；千部计划每集约 375 到 500 字，40 集共 1.5 万到 2 万字（Z3-01）
2. **纯剧本闸**：投稿正文只能是纯剧本（M2-08）；运营说明放进独立的"创作备忘"
3. **旁白闸**：不写上帝视角旁白（M4-13）；OS 依附人物，VO 写明声源（M3-07）
4. **红线闸**：先过真人微短剧内容创作建议中的严格避免与控量项（G4）
5. **依据闸**：行业数据、播放量、分账倍数、"敏感词清单"不作依据；平台没写的，只作经验参考并注明"非平台规则"

## 输入

- 一句灵感、一个题材方向、一段故事构思，或"随便给几个方向"
- 尽量说明：是否参加千部计划（截止 2026-12-31，先对照当前日期）、计划篇幅、偏男频还是女频、有无 IP
- 缺关键信息时一次问清，最多 3 问；其余按默认推进，并在备忘里写明假设

## 方向池（平台规定的方向）

| 来源 | 方向 | 规则卡 |
|---|---|---|
| 千部计划高优（收稿 80%） | 2000 年后都市或 2000 年前年代，挖掘正向情感、市井烟火；按优先级：现代都市情感、现代女性传奇、年代怀旧情感、都市脑洞、现代家庭情感、青春治愈（不涉及未成年剧情） | Z3-04 |
| 千部计划新增（收稿 20%） | 古装与架空背景，按优先级：古风情感、古代传奇人生、玄幻奇幻脑洞 | Z3-05 |
| 选题顺序 | 先定目标用户，再定题材；熟悉爽感加一个新鲜变量，新鲜点必须是核心 | M6-00、M6-08 |
| 参考 | 女性成长大女主、职业婚恋（展示专业能力与事业价值）、家庭关系成长（离婚觉醒、家庭和解、女性重建自我）对真人剧同样可借鉴 | M6-01 到 M6-03 |

## 工作流程

### 第 1 步：定用户与方向
写一句话：**给谁看、满足什么情绪**。例如"给 30 到 45 岁女性看，满足被轻视后靠专业翻身的爽感"。

### 第 2 步：类型承诺一句话
"观众点进来能得到什么情绪服务"，三集内兑现。做**三秒测试**：刷到第 3 秒能否判断这是什么类型的剧。

### 第 3 步：选设定模型（1 到 2 种为主）
| 模型 | 要点 |
|---|---|
| 身份错位 | 最强爽感发动机，身份差越大张力越大 |
| 关系逆转 | 强弱、尊卑、亲疏在关键节点翻面 |
| 命运改写 | 重来一次或预知，但不能让先知万能 |
| 强权博弈 | 不少于 3 方势力，各有诉求 |
| 秘密揭面 | 阶梯式揭面：一人知、小范围知、全场知 |
| 极端处境 | 第一集即入绝境 |
| 高概念规则 | 规则简单、内含冲突、可升级；限制比能力重要 |
| 跨类型混血 | 主轴清晰，融合后爽感增强而不是稀释 |

**冲突引擎检查**：设定会不会自己长出矛盾？需要不断编新麻烦才能推进的设定，趁早重造。

### 第 4 步：旧壳新核
熟悉的类型外壳加一个新内核，一句话讲清新在哪；新鲜点要贯穿全剧，不能提一次就没了（M6-08）。

### 第 5 步：Logline 因果链
（极致憋屈或蛰伏的主角）加（能力或身份揭露）导致（逆转命运）。念给不看短剧的人听，对方追问"然后呢"才算成立。

### 第 6 步：核心困境
给主角定 1 个主困境、1 个副困境：每个困境都是两个都要付出代价的选择，逼主角当场表态。困境不能靠让正面人物不择手段来制造（G4-05、G4-11）。

### 第 7 步：设定评估六维（每维 1 到 10 分）
识别度（初中生一听就懂）、代入度（三集内完成代入）、冲突浓度、爽点清晰度、反转容量（撑得起至少 3 次阶段转折）、延展性。**代入度或冲突浓度低于 6 分必须重构**。

### 第 8 步：平台与可拍性判断
- 篇幅：千部计划 40 集，中短篇不少于 60 集，长篇不少于 80 集（Z1-03）；主线要撑得起完稿集数
- 可拍性：主场景数、主要演员数、特效依赖，估一个量级（Z6-02）
- 备案：主要剧情是否涉及政治、军事、外交、国家安全、统战、民族、宗教、司法、公安；涉及即重点微短剧（Z4-01、Z4-04）
- 红线预判：设定本身有没有绕不开的复仇、羞辱、玄学、婚恋风险（G4）
- 原创性：未投给第三方、未公开发布（G5-01、Z3-06）

## 交付：立项卡（每个选题一张）

```
【立项卡】剧名草案（不超过 20 字符，无书名号空格，标点只用 ，！：？“”）
目标用户：
类型承诺：
设定模型：主 / 副
旧壳新核：
Logline：
核心困境：主 / 副
主角一句话：（谁，处境，要做成什么）
核心对手一句话：（为什么挡路，动机合理）
长线发动机：（个人、家族、社会三层怎么升级）
篇幅建议：40 / 60 / 80 集，理由
平台方向：对应千部计划高优或新增的哪一项
可拍性：主场景约 N 个，主要演员约 N 人，特效依赖低/中/高
备案预判：重点 / 普通 / 其他（依据）
红线风险与处理：
六维评分：识别度 / 代入度 / 冲突浓度 / 爽点清晰度 / 反转容量 / 延展性
简介草案：（避开简介 13 禁区，G2-07）
```

一次给方向时，出 3 张立项卡，标出推荐顺序与理由；用户选定后再深化一张。

## 示例

### 正例一：主场景（要投千部计划）
**输入**：想投千部计划，现实题材，最好是家庭方向，帮我出个选题。
**输出**（立项卡节选）：
```
剧名方案：老街面馆的继承人
一句话：被表姐夺走祖传卤方署名的面馆少东家，靠一碗面的手艺在老街重新立住招牌，也把散了的一家人拢回同一张桌上
目标用户：女频，25 到 45 岁，爱看家庭情感与市井烟火
情绪服务：憋屈后的扬眉吐气，加亲情修复的暖
新鲜变量：比拼的不是钱和人脉，是同一锅卤汤里谁更懂这条街
平台方向：千部计划高优方向，现代家庭情感（Z3-04）
篇幅建议：40 集全集，总字数 1.5 万到 2 万（Z3-01）
可拍性：主场景面馆、老街、表姐公司 3 处；主要演员 6 人；无特效依赖
```
**为什么好**：先定目标用户再定题材（M6-00），有"熟悉爽感加一个新鲜变量"，篇幅、方向、可拍性都落到平台口径。

### 正例二：边缘场景（用户只说"来点爽的"）
**输入**：随便来几个爽的。
**输出**：先出 3 张立项卡并排序，每张只写剧名、一句话、目标用户、情绪服务、平台方向五行；第一张标推荐理由（落在千部计划高优方向、可拍性强），请用户选定一张后再深化。
**为什么好**：需求模糊时不追问三轮，用并排方案让用户选，选定后再展开。

### 反例一：质量不足
**错误输出**：
```
题材：都市情感
主角：女强人
卖点：很爽，反转多
```
**问题**：没有目标用户、没有新鲜变量、没有篇幅与平台方向，资方和平台都无法判断。**改法**：按立项卡全字段补齐，并做"三秒测试"：刷到第 3 秒能否看出是什么剧。

### 反例二：越界过度
**错误输出**：主角借高利贷起家，再用暴力逼债复仇，理由是"现实题材占 67%，这类最好卖"。
**问题**：非法借贷与暴力复仇都是平台红线中的严格避免项（G4-05）；"现实题材占 67%"之类行业数据不是平台口径，不能作为立项依据（X-17）。**改法**：困境可以是钱，但解决靠手艺、证据与规则。

## 交接

- 选定后交 zr-cr-character（人物）、zr-cr-mainline（主线与设定）与 zr-cr-outline（大纲）
- 剧名与简介可交 zr-dx-redline 过一遍剧壳；选本吸引力可交 zr-dx-buyer

## 边界

- 不写正文；不承诺过稿率、分账金额
- 不用平台规则以外的"爆款数据"给选题打分

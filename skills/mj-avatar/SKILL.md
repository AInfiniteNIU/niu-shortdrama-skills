# AI漫剧 · 虚拟形象确权（mj-avatar）

漫剧 AIGC 创作中，虚拟形象可能来源于真人肖像、既有 IP 改编或原创角色，涉及肖像、声音、美术设计等权益。版权方在平台提报形象与权属材料申请确权，审核通过后形成确权记录，降低漫剧正片因侵权被处置的风险。

## 办事纪律（第二层通用）

- 本 skill 已内置办理所需的平台规则与操作路径（整理自短剧创作者中心帮助中心，截至 2026-11），使用时无需另查文档
- 只告诉用户怎么办、在哪里办、时限和坑；不替用户登录、填表、付款或输入证件号
- 路径与按钮名称以内置内容为准，界面以平台当前版本为准；遇到内置内容未覆盖的情况，联系平台页面右下角【客服中心】或对接商务
- 不可逆的操作（实名、身份选择、完结申请、上传时的不可改选项、账号注销）先提醒后果
- 不替用户填写身份证号、不替肖像权人核验；不提供法律意见，授权文件用平台模板，必要时咨询法务
- 功能逐步开放中，入口不可用时联系客服或对接商务确认开通

## 一、入口

| 入口 | 路径 |

| 预检 | 平台预检工具检测到肖像权风险后，如已取得授权，前往提交确权材料 |

## 二、新建形象（内容与关联角色、权属材料保持一致）

| 字段 | 要求 |
|---|---|
| 虚拟形象名称 | 必填，可检索选择已关联的漫剧角色 |
| 头像 | 必填，清晰可识别，用于平台展示 |
| 其他图片 | 选填，全身、半身、立绘等，辅助审核 |
| 简介 | 必填，10 到 100 字 |
| 关联剧集 | 必填 |
| 形象类型 | 必填：基于真人形象改编 / 基于已有 IP 改编 / 原创 |

头像与立绘可直接用 mj-cr-character 的形象锚点卡和 mj-cr-handoff 的角色资产。

## 三、三类确权材料

### 1. 基于真人形象改编
- **授权文件**：载明授权人（真实姓名、身份证号、肖像照片）与被授权人的主体信息，明确授权范围（漫剧名称、角色名称、使用场景）；平台提供个人签章版与机构加个人签章版模板
- **肖像权人知悉证明**（二选一）：① 证件核验：上传肖像权人有效身份证正反面清晰照片，信息与授权一致；② 人脸核验：生成邀请码，肖像权人本人扫码登录完成人脸认证

### 2. 基于已有 IP 改编
- 从原始权利人到当前使用方的**完整授权链**证明（有模板）
- 原始 IP 名称与对应角色图片

### 3. 原创虚拟形象
- 权属材料当前非必填；已有的可上传著作权登记证书、可信时间戳作品认证或版权存证证书，作为初步证据帮助提升审核效率
- 经验建议（非平台规则）：定稿形象尽早存证，保留生成与修改过程记录

提交后按流程审核，结果以页面状态为准。

## 四、一致性提醒

- 角色外形一旦确定要全剧一致，否则既影响确权，也不符合画风一致的审核要求（M9-05、M8-08）
- 不让外形明显指向真实公众人物；未取得授权不使用真人肖像（G4-09）

## 五、入驻红果

- 确权审核与安全审核都通过、满足条件后，在列表操作栏或详情页右上角点【入驻红果】
- 填操作人姓名与身份证号并完成手机号校验（由用户本人填写）
- 绑定成功后登录红果 App 以虚拟角色账号经营

## 交接

一致性与权属风险先过 mj-dx-visual；形象设计见 mj-cr-character；上传见 mj-release-ops。

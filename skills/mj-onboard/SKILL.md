# AI漫剧 · 入驻与认证（mj-onboard）

## 办事纪律（第二层通用）

- 本 skill 已内置办理所需的平台规则与操作路径（整理自短剧创作者中心帮助中心，截至 2026-11），使用时无需另查文档
- 只告诉用户怎么办、在哪里办、时限和坑；不替用户登录、填表、付款或输入证件号
- 路径与按钮名称以内置内容为准，界面以平台当前版本为准；遇到内置内容未覆盖的情况，联系平台页面右下角【客服中心】或对接商务
- 不可逆的操作（实名、身份选择、完结申请、上传时的不可改选项、账号注销）先提醒后果

## 一、漫剧走哪个身份

| 你要做的事 | 身份 |
|---|---|
| 上传自己制作的漫剧成片、分成 | 版权人（个人）或版权机构（对公） |
| 用平台 IP 库改编漫剧 | 版权方，且获得成品框架分成后自动开通 IP 库权限 |
| 以编剧、导演身份与平台合作漫剧 | 已有投稿标准（平台 2026-11 发布 AI 剧投稿模板与长篇创作要求），入口以站内为准；剧本按投稿模板 13 项准备 |

### 身份规则
- **漫剧版权人**可以继续认证编剧、导演、演员（与短剧版权人不同）
- 版权人与版权机构不能共存（不论体裁），先想清楚以个人还是公司签约结算
- 只做漫剧的版权机构，可直接在【我的头像】→「添加身份」新增漫剧体裁的其他主创身份；要新增真人短剧主创身份，需先增加短剧体裁版权方再转变合作模式

## 二、原平台老用户

- 原"短剧版权中心"的机构 CP 管理员或个人 CP 直接用手机号登录（不支持邮箱登录），原合同、内容、数据保留
- 同时用过版权中心和红果创作服务平台、且手机号一致的，登录后弹出身份融合确认
- 在原版权中心签过合同的，可跳过重新签约

## 三、入驻步骤

1. 「手机登录」注册；机构用公司手机号
2. 选身份并选"漫剧"体裁，点「立即认证」
3. 个人实名或企业认证（主体资质 + 对公验证）。对公验证五种方式：
   - 法人人脸：二维码 24 小时内用法人已实名支付宝扫码（推荐）
   - 法人银行卡实名：校验即过，不打款
   - 平台向客户打款：仅 2 次打款机会，收款后 48 小时内回填金额，每次 2 次输入机会
   - 客户向平台打款：48 小时内打出，以回执单为准，避开周末节假日
   - 账户授权：授权账户须已通过对公验证且名称、类型一致
4. 审核：个人一般 2 个工作日，机构一般 3 个工作日

实名不支持解除或换绑；公司名称、社会代码、法人不可改；资质照片 jpg、png、jpeg，不超过 5M；版权机构下绑定的主体不能与其他创作者机构互通复用。

## 四、机构账户

- 管理员变更：管理员在【成员管理】点【添加账号】，类型选【管理员】并输入手机号（对方需注册登录）；离职前本人点【移除】；唯一管理员要先增加人再移除
- 发布抖音号：机构可绑定企业机构号或个人抖音号，账户维度总计上限 200 个
- **账号注销会连带头条号、番茄作家平台、番茄小说、短剧创作者中心一起失效**（G5-14）
- 客服：页面右下角【客服中心】，漫剧客服 09:00 到 19:00

## 交接

版权方入驻后转 mj-submit-sign（合作模式与签约）、mj-release-ops（上传）、mj-avatar（形象确权）。

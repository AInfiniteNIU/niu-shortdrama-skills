# 真人剧 · 入驻与认证（zr-onboard）

## 办事纪律（第二层通用）

- 本 skill 已内置办理所需的平台规则与操作路径（整理自短剧创作者中心帮助中心，截至 2026-11），使用时无需另查文档
- 只告诉用户怎么办、在哪里办、时限和坑；不替用户登录、填表、付款或输入证件号
- 路径与按钮名称以内置内容为准，界面以平台当前版本为准；遇到内置内容未覆盖的情况，联系平台页面右下角【客服中心】或对接商务
- 不可逆的操作（实名、身份选择、完结申请、上传时的不可改选项、账号注销）先提醒后果

## 一、先选对身份

| 身份 | 个人 / 机构 | 能做什么 |
|---|---|---|
| 编剧 | 个人、编剧机构 | 选 IP、建剧本投稿；查看署名短剧收入；机构可管理成员、查看机构剧本创作情况 |
| 导演 | 个人、导演机构 | 机构参与项目撮合、承接执导与制作；查看署名收入 |
| 演员 | 个人、演员机构 | 参与撮合；查看署名收入；机构管理旗下演员与邀约状态 |
| 版权方 | 版权人、版权机构 | 成品剧版权合作、上传经营、查看上线短剧的持续消费情况。注意上传资格：新平台入驻的版权机构不能上传成品真人短剧（只能上传漫剧），原短剧版权中心的机构用户暂时可以（Z5-06）；个人版权人认证时可选真人剧、漫剧体裁 |
| 投资出品方 | 机构 | 选剧本、组团队、撮合生产（由版权机构转变合作模式或经商务开通） |

### 互斥规则（按钮变灰多半是这里，点「详情」可看原因）
- 认证了**短剧版权人**，不能再认证任何短剧主创身份（编剧、导演、演员及其机构）；漫剧版权人不受此限
- 版权人与版权机构不能共存（不论体裁）
- 短剧版权机构要新增主创身份，先转变合作模式（成品剧闭环合作转为撮合合作），转变后获得投资出品机构身份
- 个人身份审核中，不能并行发起其他个人身份和短剧版权机构认证，但可发起机构主创认证；短剧版权机构审核中，不能并行发起其他短剧主创机构认证

提醒：既想当编剧、又想上传自己拍的成品剧，先想清楚走哪条路；短剧版权人一旦认证，就不能再当短剧编剧。

## 二、入驻四步

1. **注册登录**：登录页选「手机登录」，新手机号点「登录/注册」自动注册，可设密码；忘记密码用手机验证码登录或「忘记密码」。机构建议用公司手机号（账号关联合同与结算）
2. **选身份**：新用户进入"创作者身份选择页"点「立即认证」；老用户点右上角头像，「添加身份」
3. **实名或企业认证**（见下节）
4. **职业信息与作品认领**（见第四节）

审核时效：个人身份一般 2 个工作日，机构身份一般 3 个工作日；结果以短信和站内信通知，也可在"创作者身份选择页"点「查看审核详情」。

## 三、实名与企业认证

### 个人实名
- 实名手机号可以和登录手机号不同；已有完整实名信息的，新增身份时无需重填
- **不支持解除或换绑实名**；个人的姓名、身份证号不可改，其余可改
- 修改路径：「账号与信息管理」→「账号身份信息」→「我的实名」右侧修改
- 改银行卡后，已签合同默认不更新打款账号，需联系商务签补充协议（尽量不改）

### 企业认证 = 填写主体资质 + 对公验证（两步都要完成，建议一次填完提交）
- 公司的公司名称、社会代码、法人不可改；个体户同一账号最多认证 5 个，经营者不可重复
- 资质照片仅支持 jpg、png、jpeg，不超过 5M，选含"资质编号"的照片
- 版权机构下绑定的主体不能与其他创作者机构互通复用，需重新填写

| 对公验证方式 | 要点与时限 |
|---|---|
| 法人或经营者人脸识别（推荐） | 二维码生成后 24 小时内，用法人本人已实名的支付宝扫码，首次需"同意并认证" |
| 法人或经营者银行卡实名 | 填法人身份证号、个人银行卡号、预留手机号与验证码，校验通过即完成，不打款 |
| 平台向客户打款 | 一个账户仅 2 次打款机会；预计 2 小时内到账（节假日可能延迟）；收款后 48 小时内回填金额，每次打款仅 2 次输入机会 |
| 客户向平台打款 | 发起后 48 小时内用所填卡打出指定金额；以打款回执单为准（受理单、申请单不算）；尽量避开周五到周日与节假日 |
| 账户授权验证 | 授权账户须已用前四种方式之一通过，且公司名称、验证类型一致；被授权账户当前有效期大于 30 天不可申请 |

常见卡点：对公打款需要法人或财务审批才真正汇出；公司改过名但对公账户名未改，会报"账户名不符"；平台显示"收款中"时，一般 3 到 4 小时到账，超过 24 小时先查回执单卡号。

## 四、职业信息与作品认领

- 先完成实名（个人）或企业认证（机构）
- 入口：「账户与信息管理」→「账号身份信息」→「个人职业信息填写」（机构为「机构职业信息填写」，仅超管和管理员可操作）；或首页对应卡片
- 先搜姓名或艺名认领已收录身份；搜不到点"以上都不是我，创建新身份"
- 名称用实名或有公信力的艺名、厂牌名，不重名不蹭名；简介 10 到 100 字，不夸大不导流；审核 1 到 3 个工作日
- **作品认领**：入驻第三步"作品认领"，或「账号与信息管理」→「我的署名短剧」→「认领作品」
  - 编剧：身份证明、至少前 30% 剧本，加编剧合同或作品著作权登记证书之一
  - 演员、导演：身份证明，加合同或协议、官方封面海报、片尾演职人员表、现场工作证明（剧组工作照、开机杀青仪式、定妆安排、通告单）、出品方厂牌签章证明之一
  - 审核 3 到 7 个工作日
- **署名即确权**：未署名或署名不一致，看不到作品数据

## 五、机构成员与账号

- 成员管理：超管或管理员在【账号管理】→【成员管理】添加成员（可同时输入多个手机号，对方注册实名后在消息中心确认）、设为管理员、移除；唯一管理员要先加人再移除自己
- 导演机构"添加成员"点不了：先在合同管理签"导演框架协议（导演机构-含个人导演）"
- 抖音企业机构号（B 号）：短剧机构主账号要求企业主体已认证并已在短剧创作者中心入驻；头像、昵称、简介与认证主体一致或相关，昵称以企业名或商标名为主
- 发布短剧的抖音号：机构可绑定企业机构号或个人抖音号，账户维度总计上限 200 个
- **账号注销会连带头条号、番茄作家平台、番茄小说、短剧创作者中心一起失效**（G5-14）

## 交接

入驻完成后：编剧转 zr-submit-sign；投资出品方、导演、演员转 zr-matchmaking 或 zr-crew；版权方转 zr-release-ops。

# AI漫剧 · 人设与形象锚点（mj-cr-character）

目标：做出**观众愿意追、画得稳、全剧不变脸、能确权**的人物组，交出投稿模板第 12 项和形象锚点卡。

## 五道闸（第四层通用，动笔前先过）

1. **字数闸**：长篇超过 70 集、全剧不低于 7 万字（折算约每集 1000 字），单集观看 1 到 2 分钟（M1-01、M1-02）
2. **纯剧本闸**：投稿正文只能是纯剧本，分镜、提示词、资产卡、运营标注、修改痕迹一律不进正文（M2-08）；说明放进独立的"创作备忘"
3. **旁白闸**：不写叙述旁白与第一人称解说；成品框架分成合作不收旁白解说类（M1-04、M4-13）；OS 依附人物，VO 写明声源（M3-07）
4. **红线闸**：漫剧红线比真人剧更严（G4 加 M8），剧本里写的都会被画出来
5. **依据闸**：行业数据、播放量、分账倍数不作依据；平台没写的只作经验参考并注明"非平台规则"

## 平台校准

- 人设七字段：姓名、性别、年龄、身份、性格、人物目标、与主角关系，每人 50 到 100 字（M2-04）；与正文一致（M2-07）
- 主角主动选择、台词有区分、反派不只喊狠话（M4-12）；遮住名字也分得出谁在说（M5-12）
- 女频重关系递进与人物吸引力，男频重获得感与他人认可（M4-07、M4-12）
- 主角正面讨喜（G4-11）；不称赞鼓励出轨（M8-02）；服饰不暴露不擦边（G4-08）；形象不怪异扭曲恐怖（M8-05）；未成年角色守 G4-10、M8-07
- 角色外形一旦确定全剧一致，否则影响确权，也违反画风一致要求（M9-05、M8-08）
- 形象来源三类：基于真人需肖像授权，基于已有 IP 需授权链，原创可做著作权登记或时间戳（M9-01）；不让外形明显指向真实公众人物（G4-09）
- 高颜值强建模是平台推荐方向（M6-07）

## 方法

1. **主角七维**：核心欲望、核心伤口、不可替代能力（要有画面表现）、压抑状态、爆发方式、上升路径、一句话记忆点
2. **标签加反差**：3 到 5 个标签，至少一对矛盾，首次登场 3 个动作内被感知，分早中后揭示
3. **人物内核一句话**与**背景弹药化**（3 到 5 个可引爆的前史事件）
4. **金手指与降智防火墙**：一两种，分阶段释放，有代价或限制；对手有反信息差
5. **反派三层**：执行者、幕后推手、终极对手；理性动机，有阶段性胜利；惩治不过度（M8-03）
6. **CP 工程**：势均力敌、"只对你不同"、推拉节点、潜台词；强视觉关系（身高差、色彩对照、标志物呼应）可以充分利用
7. **高吸附原型**（经验参考）：绝对理智利己者、扮猪吃虎隐忍者、双标偏爱矛盾体；强反差、极致执行力、有当代共鸣的缺陷
8. **配角生态**：每人至少 2 个功能和 1 个记忆点；配角外形与主角拉开区分度，避免 AI 画成一张脸
9. **信息差悬念网**与**角色卡三问**

## 形象锚点卡（每个主要角色一张）

```
角色名：
年龄感：           身高体型：
脸型与五官特征：
发型与发色：       瞳色：
常穿服装（按阶段）：
标志物：（一件全剧反复出现的东西）
表情组：常态 / 怒 / 笑 / 隐忍 / 爆发
阶段变化：换装、觉醒、受伤等节点及对应集数
形象来源：原创 / 基于真人（授权情况）/ 基于已有 IP（授权链）
确权简介（10 到 100 字）：
```

年龄感、脸型、发色、瞳色全剧内不改；服装与状态变化必须登记集数，写正文时对照。

## 交付

1. **投稿模板第 12 项：主要人设**（每人 50 到 100 字，七字段）
2. **形象锚点卡**（生产文件，交 mj-cr-handoff 与确权）
3. **创作备忘**：主角七维卡、反派三层表、CP 推拉节点、配角功能表、信息差悬念网、人物状态表

## 写完自检

交 mj-dx-package 查第 12 项；交 mj-dx-visual 查外形一致性与形象权属。

## 示例

### 正例一：主场景（主角人设与形象锚点）
**输入**：把杂役主角的人设和形象定下来。
**输出**：
```
人设：沈烬，男，19 岁，青云宗烧炉杂役。少言、记账、认死理，挨了欺负先记下来再还。目标：炼出一件让长老无法否认的神兵，进内门。与主角关系：本人。
形象锚点：黑发高束，右眉一道浅疤；灰色短打杂役服，袖口常年被火燎焦；左手腕缠一圈旧铁链（器灵所在）。
不可变项：眉疤、铁链、焦袖口。可变项：外袍、发饰。
```
**为什么好**：人设七字段齐全（M2-04）；锚点写成可画的外形特征，标出不可变项，全剧不变脸（M9-05、M8-08）。

### 正例二：边缘场景（原型像某个明星）
**输入**：男主我想照某个当红演员的脸来画。
**输出**：未取得授权不使用真人肖像（G4-09）；如确需基于真人形象，要拿到肖像授权并完成确权（M9-01，办理见 mj-avatar）。建议改为原创脸，用眉疤和铁链做辨识。

### 反例一：质量不足
**错误输出**：`沈烬：很帅，很强，穿黑衣。`
**问题**：没有可锁定的特征，AI 每集画出来都不一样。

### 反例二：越界过度
**错误输出**：女配设定为"暴露服装、擦边身材"作为卖点。
**问题**：角色造型暴露擦边属于低俗控量项，漫剧画出来更明显（G4-08）。

## 边界

- 不生成图片，不写定妆照提示词（交 mj-cr-handoff 与用户已有的虚拟演员或分镜 skill）
- 不仿写真实人物或已有 IP 角色的外形

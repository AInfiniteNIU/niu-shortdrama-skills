# AI漫剧系统 · 知识库与路由（manju-hub）

## 定位

AI漫剧（含 2D、3D 漫剧和 AI 仿真人剧）skill 系统的第一层。它做两件事：

1. **知识库**：把短剧创作者中心 37 篇帮助文档抽成结构化规则卡，回答"平台怎么规定"，每条答案都能追溯到规则卡编号、平台来源与日期；规则全文已内置，无需另查平台文档
2. **路由**：把办事、诊断、创作类需求分发到 mj 系列 skill

四层分工：第一层回答"去哪里、规则是什么"；第二层回答"平台上怎么操作"；第三层回答"这样写平台收不收、签不签、资方选不选、能不能过审"，只诊断不写稿；第四层负责写剧本，写完交第三层自检。

## 工作流

**Step 1 · 识别三件事**
- 品类：AI漫剧、AI剧、AI仿真人剧（另一个品类的问题，提示改用 zhenren-hub）
- 身份：编剧、编剧机构、版权方、投资出品方、导演、演员、演员机构
- 环节：入驻认证、投稿签约、撮合、创作、诊断、上线审核、经营、结算

**Step 2 · 判断需求类型，按路由表分发**
- 问规则、问"平台允不允许、要求是什么" → 本 skill 直接回答（Step 3）
- 问"平台上怎么操作" → 第二层办事型
- 问"这样写平台收不收、签不签、资方选不选、能不能过审" → 第三层诊断型
- 要"帮我写" → 第四层创作型
- 目标 skill 尚未安装时，本 skill 直接给出依据规则卡和最小可用答复，并说明完整能力属于哪个 skill

**Step 3 · 查规则卡作答**
- 只依据下方规则卡库回答，每条结论都标出规则卡编号和平台来源（文档名）
- 规则卡里没有的，明确说"文档未覆盖"，建议联系「短剧创作者中心右下角客服中心」，不凭经验补数字
- 涉及金额、比例、日期，补一句"最终以站内信和签署的合同为准"（G5-09 来源文档的原文说明）

**Step 4 · 时效检查**
- 用当前日期对照规则卡的状态和日期：已截止的规则只能作参考，不能作为当前可参加的活动推荐
- 规则卡库版本为 v1.1（文档抓取并复核于 2026-11-17；线上 37 篇最近一次更新为 2026-11-11）；当前日期距此超过 90 天，或用户提到"新政策""刚改了"，提示重新抓取文档核对

**Step 5 · 冲突裁决**
- 平台规则与创作方法论（包括用户已有的其他编剧 skill）不一致时，投稿和上线一律以平台规则为准，见"冲突裁决"表
- 文档之间不一致（状态为"待核"），说明两种表述，给出保守做法

## 答复格式

```
结论：一句话
依据：
- [规则卡编号] 规则要点（来源：平台文档名，生效日期或状态）
提醒：时效、待核项、以合同为准等（没有就省略）
下一步：对应的 skill 或操作入口（没有就省略）
```

> 强度：【硬】明文要求，违反即退稿、驳回或无法上线；【控】"避免在全剧中过多展现"，控量即可；【荐】推荐方向或写法。

# 真人剧 · 红线与剧壳诊断（zr-dx-redline）

回答一个问题：**这部剧的内容和剧壳，过不过得了安全审核与成片审核？**

## 输入

- 剧本正文（全集或待查集数）、剧名、简介；有封面时提供封面描述或图片
- 预计总投资区间（用于备案分层）

### 借用他人作品（人工判断）
台词、角色名、编号、招牌名场面、剧名明显借用他人作品（例如经典电影的标志性台词或道具名）时，列入"人工判断"：已获授权的，提醒备好授权链与剧名一致的材料（G5-01、G1-05）；未获授权的，建议替换为原创表达。致敬不等于侵权，但平台按"投稿须原创、严禁抄袭"审核。

### 判定要点（每个命中项都要回答）
1. **谁做的**：主要正面人物，还是反派；反派的恶行是否被批判、受到对等惩罚
2. **什么背景**：现代非架空，还是古代、架空、玄幻；很多条目只在"现代背景"或"非合理背景"下严格
3. **怎么呈现**：细节展示过程，还是一笔带过、结果呈现
4. **频次**：控量项统计全剧出现次数和集中度，同类在 3 集内反复出现即标"建议改"
5. **导向**：作品整体是否破除迷信、肯定法治、正向结局

真人剧与漫剧口径差异：真人剧"出轨偷情"为控量项，漫剧的称赞鼓励出轨为严格避免（M8-02）；本 skill 按真人剧口径。

## 四、质量项（平台《真人微短剧内容创作建议》）

- 整剧：剧集缺失、乱序、断更烂尾、剧情不连贯（G3-01）
- 单集：剧集或剧情重复；段子合集、多剧拼接；画幅、音画、字幕缺陷；其他平台水印或备案号；私下广告引流（G3-02、G3-03）

## 流程

1. 分段通读全剧，建"命中表"：集数、场次、原文要点、类别、严格或控量
2. 对每个命中项回答五个判定要点，定级
3. 统计控量项的全剧频次与分布
4. 判断备案层级
5. 检查剧名、简介、封面
6. 输出报告；"修改方向"给出保留戏剧张力的合规处理思路（例如把暴力复仇改为证据与规则反制），不代写

## 诊断纪律（第三层通用）

- **只诊断，不写稿**：可以给一句修改方向或一行示意，不重写段落；改稿交给第四层（zr-cr-revise）
- **每条问题都要有出处**：位置（第几集第几场或第几行）、规则卡编号、原文要点
- **分级**：
  - 必改：违反【硬】规则，不改会退稿、驳回或无法上线
  - 建议改：违反【控】规则或【荐】写法，影响评级或过稿率
  - 人工判断：关键词或情节存在风险，需要结合上下文确认
- **不凭经验加规则**：规则卡没有的标准不作为扣分依据，可在"补充意见"里单列并注明"非平台规则"
- **时效**：引用有截止日期的规则（如千部计划 2026-12-31）时，先对照当前日期

## 报告格式（固定）

```
诊断结论：可投 ／ 需改后投 ／ 不建议投
一句话理由：……

一、必改（共 N 条）
| # | 位置 | 问题 | 规则卡 | 修改方向 |

二、建议改（共 N 条）
| # | 位置 | 问题 | 规则卡 | 修改方向 |

三、人工判断（共 N 条）
| # | 位置 | 风险 | 规则卡 | 判断要点 |

四、通过项
- 逐项列出已检查且合格的项目

五、交接
- 交给哪个第四层 skill 改，按什么顺序改
```

结论判定：有任何一条"必改"即不能判"可投"；必改项集中在价值观红线或"小说直转、AI 直出"时判"不建议投"。

## 示例

### 正例一：主场景（情节能不能过审）
**输入**：第 15 集周倩让人把林晚的面馆砸了，林晚第二天带人去砸回来，行吗？
**输出**：
```
| 必改 | 第 15 集 | 主角以暴制暴、私力报复，现代背景不用暴力和违法手段 | G4-05 |
修改方向：林晚报警并调取监控，用证据让对方赔偿，惩罚交给法律
```
**为什么好**：指出规则与位置，只给一句修改方向，不重写段落。

### 正例二：边缘场景（剧名与封面）
**输入**：剧名想叫《老街面馆：豪门千金的逆袭》，封面用两人贴脸的亲密照。
**输出**：剧名标点与字数合规（G2-04、G2-05）；但"豪门千金"与正文不符属于套壳（G2-06）；贴脸亲密照需确认是否属于非正当婚恋关系的亲密互动（G2-08），男女主是正当恋人关系可用，但不宜过度。

### 反例一：质量不足
**错误输出**：`有点敏感，建议改改。`
**问题**：没说哪类红线、严格避免还是控量、位置在哪。

### 反例二：越界过度
**错误输出**：把所有吵架、冲突场面都判为"必改"，并建议删到没有冲突。
**问题**：把控量项当成严格避免项，诊断过严会毁掉剧作；只标真正触线的内容，控量项给出全剧次数建议。

## 边界

- 平台文档未列明的说法（例如网络流传的"敏感词"清单）不作为判定依据，可在补充意见中提示并注明"非平台规则"
- 不给法律意见；涉及真实人物、真实企业、真实事件改编的，提示用户取得授权或咨询法务

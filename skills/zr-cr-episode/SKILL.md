# 真人剧 · 单集剧本（zr-cr-episode）

目标：按分集卡写出**能直接上传、能拍、每集都有推进**的纯剧本正文。

## 五道闸（第四层通用，动笔前先过）

1. **字数闸**：每集 600 到 800 字，上限 1200（Z1-01）；千部计划每集约 375 到 500 字（Z3-01）。任何"每集 3000 字"之类的参数都不采用，节奏按比例缩放
2. **纯剧本闸**：正文不出现【BGM】【音效】、景别运镜、爽点钩子付费卡点名场面投流等标注、本集复盘（M2-08）
3. **旁白闸**：不写叙述旁白（M4-13）；OS 依附人物且每集少量；VO 只用于有声源的画外声（M3-07）
4. **红线闸**：羞辱、家暴、复仇、亲密戏、玄学、未成年情节先对照 G4
5. **依据闸**：平台没写的写法只作经验参考

## 输入

- 分集卡（来自 zr-cr-outline），至少含当集任务、看点、结尾悬念类型
- 人物设定与人物状态表；上一集正文（续写时必需）
- 没有分集卡时，先用 zr-cr-outline 补一份覆盖本批的最小版

## 动笔前自检（每集）

1. 本集在分集卡中的任务、看点、结尾悬念类型
2. 上集悬念怎么在前 3 行接住
3. 字数目标（普通 600 到 800，千部计划 375 到 500）
4. 有无红线风险点
5. 本集场景数与出场人数（可拍性，Z6-02）

## 方法

### 1. 单集结构（按比例）
开场钩子约 1 成、冲突升级约 3 成、核心戏剧与反转约 4 成、悬崖收束约 2 成。600 到 800 字就是：承接 1 到 3 行、一场主冲突、一个转折、一个卡点。

### 2. 单集弧线
开场高能、信息建立、冲突攀升、峰值、短暂喘息或新信息、二次攀升、更大峰值、极限钩子骤停。字数紧时只保一次峰值。

### 3. 峰值类型
打脸、揭秘、危机、情感、逆转、联手、清算。相邻两集不用同一种。

### 4. 反转三拍
建立预期、延伸预期、打碎预期。打碎的依据必须在前面埋过（M4-08）。

### 5. 集尾八技
卡动作、卡身份、卡情感、卡生死、卡真相、卡反转、新威胁、视觉悬念。停在未完成的动作、危险、误会、揭示或关系推进上（M3-11），然后写"（本集完）"。不靠一句"悬念台词"硬贴，要把悬念演出来。

### 6. 连续性缝合
开场前 3 行接住上集悬念，不跳过不弱化（集首承接只复现 1 到 3 行，M3-10）；情绪状态承接上集；结尾除钩子外再留 1 条新线索；新元素 2 到 3 集内产生影响。

### 7. 呼吸与场景纪律
高密度对白后用动作行换气；一段不产生新信息就是注水。场景少而精，直接跳切，不写"与此同时""另一边"和"转场"；展示决定后直接跳到结果；每次换场带来新信息。

### 8. 动作行即表演指令
写"指甲掐进掌心"，不写"她感到心痛"。能用动作说的不用对白；一行一个动作，主语明确，演员拿到就能演（M3-04）。

### 9. 内心戏外化四法（按优先级）
行动化、对话化、闪回（交代起止）、OS（最克制，依附人物）。

### 10. 大场面落细节
谁的手在抖、哪件东西先碎、谁先开口、旁人什么反应（M5-03）。真人剧的"大场面"也要控制群演人数。

### 11. 3 集小弧线
批量写时以 3 集为一组：矛盾建立、激化、微解决或大悬念。每组写完回查人物状态表（M5-04）。

## 场景模板（已过平台校准）

| 模板 | 步骤 | 约束 |
|---|---|---|
| 打脸 | 造高台、围观烘托、主角不动声色、埋裂缝、旁人发现、主角收网、对手崩裂、围观翻转、收获结算 | 对手不降智，不信要有利益、面子或信息不全的理由；羞辱动作控量；不用贫富对立拉仇恨 |
| 身份揭露 | 伏线回收、对方自己发现或第三方揭破、阶梯式揭面、围观态度剧变、被揭露者微表情、关系重构、暗示更深秘密 | 分阶段释放，揭示前有铺垫 |
| 情感高潮 | 氛围铺垫、缓慢接近、数行无对白、一句极简台词、闪回呼应、画面定格 | 克制，不写身体部位与性暗示（G4-08） |
| 卡点集 | 前 2 集蓄力、推到不可调和、临界一击、在关键信息即将完成时停住 | 只写"（本集完）"，不写运营标注 |
| 虐与转折 | 前置铺垫、先让观众喜欢才有痛感、虐后给希望 | 打压后必须有反击和反馈（M5-06）；家暴与羞辱控量 |
| 冷却与过渡 | 高潮后缓冲，必须塑人物、推关系或埋伏笔 | 过渡集也要有效推进（M4-10） |

复仇类情节：手段用证据、规则、专业能力、公开真相；惩罚交给法律与规则，与过错对等（G4-05）。

## 正文格式

```
第十二集

12-1 地点 时间 内/外
出场人物：甲，乙

△动作行。
甲（语气）：台词。
乙（OS）：台词。
【字幕：丙/身份】（重要角色首次出场时）

（本集完）
```

集号用中文数字；台词括号里只写语气，不塞导演说明；一句台词服务一个目的，短句优先但不设硬字数；不用破折号堆叠，不用"不禁、不由得、涌起一股"之类 AI 高频词（M5-13）。

## 交付

1. **正文**：纯剧本，按集顺序，可批量导入（按标题覆盖，Z2-05）
2. **创作备忘**（另起）：每集字数、场景数、出场人数；峰值类型与结尾悬念类型；伏笔埋设与回收；人物状态表更新；与分集卡的偏差及理由

## 写完自检

运行本 skill 目录 scripts/check_script.py（`--mode zr`，千部计划 `--mode qianbu`），再按 zr-dx-rejection 的 12 类问题抽查；红线风险点交 zr-dx-redline。定点回改，最多两轮。

## 示例

### 正例一：主场景（合格的单集片段）
**输入**：按分集卡写第 3 集。
**输出**（片段）：
```
第三集

3-1 林记面馆 夜 内
出场人物：林晚，王婶，周倩
△上一集结尾那本被翻乱的账本还摊在桌上。
王婶（推门进来，喘着气）：晚晚，你爸当年借我的那口铜锅，锅底刻着字。
△林晚接过铜锅翻过来，锅底刻着"林记卤方，戊午年"。
林晚（OS）：公证是去年的事，这口锅比她早了四十年。
△门外的灯亮了，周倩站在台阶下。
周倩：你拿一口锅，能证明什么？
林晚：明天开街，我请整条街的人来尝。尝过的人自己会说。
（本集完）
```
**为什么好**：开头接住上一集，信息点落在可拍的物证上；OS 依附人物（M3-07）；集尾停在将要发生的公开对决（M3-11），格式全部按平台模板。

### 正例二：边缘场景（千部计划单集篇幅）
**输入**：千部计划的单集也写 700 字吗？
**输出**：不，千部计划 40 集总字数 1.5 万到 2 万，折合每集约 375 到 500 字（Z3-01）：每集控制在 2 到 3 场，只保留一个信息点和一个钩子。

### 反例一：质量不足
**错误输出**：
```
林晚很生气，她觉得表姐太过分了，于是决定一定要拿回卤方。她想了很久，终于想到了办法。
```
**问题**：小说叙述，没有场次、出场人物、动作行与对白（M3-02 到 M3-06），也拍不出来。**改法**：拆成场，用动作和台词把"决定"演出来。

### 反例二：越界过度
**错误输出**：正文写到 2000 字，每场标【BGM：悬疑】【镜头：特写推近】，结尾写【本集结束】并附"本集创作复盘"。
**问题**：超过 1200 字上限（Z1-01）；BGM、镜头、复盘都不进正文（M2-08）；集尾要写"（本集完）"（M3-12）。

## 边界

- 不重排大纲；分集卡有硬伤时先回 zr-cr-outline
- 不写分镜、拍摄计划

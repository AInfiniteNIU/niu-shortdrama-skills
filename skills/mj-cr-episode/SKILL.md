# AI漫剧 · 单集剧本（mj-cr-episode）

目标：按分集卡写出**能直接投稿、每行都能画、靠对话和表演推动**的纯剧本正文。

## 五道闸（第四层通用，动笔前先过）

1. **字数闸**：单集 1 到 2 分钟体量（M1-02）；全剧不低于 7 万字，折算平均每集约 1000 字（M1-01）。来源里的"每集 3000 字""每集 500 到 800 字"都不采用
2. **纯剧本闸**：正文不出现分镜表、景别运镜、提示词、角色资产卡、【BGM】、爽点钩子卡点名场面视觉奇观等标注、本集复盘（M2-08）
3. **旁白闸**：不写叙述旁白、不用第一人称解说（M1-04、M4-13）；OS 每集少量且依附人物；系统音、广播用 VO 并写明声源（M3-07）
4. **红线闸**：写什么就会画什么。写实血腥、断肢、怪异扭曲形象、暴露服饰不写；过度报复不写（G4、M8）
5. **依据闸**：平台没写的写法只作经验参考

## 输入

- 分集卡（mj-cr-outline）、人设与形象锚点卡、世界观要点、设定与人物状态表
- 上一集正文（续写必需）；没有分集卡时先补一份覆盖本批的最小版

## 动笔前自检（每集）

1. 本集任务、看点、视觉奇观（如有）、结尾悬念类型
2. 上集悬念怎么在前 3 行接住
3. 本集主要信息由哪几个角色当面对抗交代（不是一个人讲给观众听）
4. 角色外形有无变化（换装、受伤、变身），与形象锚点卡对齐
5. 有无红线风险点

## 方法

1. **单集结构（按比例）**：开场钩子约 1 成、冲突升级约 3 成、核心戏剧与反转约 4 成、悬崖收束约 2 成
2. **单集弧线**：开场高能、信息建立、冲突攀升、峰值、短暂喘息或新信息、二次攀升、更大峰值、极限钩子骤停
3. **峰值类型**：打脸、揭秘、危机、情感、逆转、联手、清算、觉醒。觉醒写法：困境极限、顿悟、突破（天象异变的仪式感）、旁观震惊、新能力立即解决当前困境。相邻两集不用同一种
4. **反转三拍**：建立预期、延伸预期、打碎预期；依据前面埋过（M4-08）
5. **集尾八技**：卡动作、卡身份、卡情感、卡生死、卡真相、卡反转、新威胁、视觉悬念。悬念要演出来，不贴一句"集末钩子"式空话（M5-13）；最后单独一行"（本集完）"
6. **连续性缝合**：前 3 行接住上集（集首承接只复现 1 到 3 行，M3-10）；情绪承接；结尾再留 1 条新线索；新元素 2 到 3 集内产生影响
7. **动作行可画**：写可见的动作、表情、画面；一行一个连续动作单元；多人同场时每行主语明确（M3-04）；大场面落到谁先动、哪件东西先碎、旁人什么反应（M5-03）；情感视觉化（压抑用冷色雨雾、觉醒用暖金光柱、心动用暖色柔光）写进动作行，不单列镜头指令；信息揭示确实依赖画面时，可用一次【镜头特写】之类标记（M3-08）
8. **心理外化四法**：行动化、对话化、闪回（交代起止）、OS（最克制）。纯 NPC 对话缺画面、纯画面缺对话都是 AI 跑稿痕迹
9. **单一主视角**：事件收束回主角；配角反应只写主角在场可见的；要让观众知道主角不知道的危险，用可见的物证或动作暗示，不切到反派视角大段叙事（M4-13）
10. **3 集小弧线**：批量写时每 3 集一组，写完更新设定与人物状态表（M5-04）

## 场景模板（已过平台校准）

| 模板 | 步骤 | 约束 |
|---|---|---|
| 打脸 | 造高台、围观烘托、主角不动声色、埋裂缝、旁人发现、主角收网、对手崩裂、围观翻转、收获结算 | 对手不降智；羞辱动作控量；不以贫富对立拉仇恨；富人欺凌贫弱控量（M8-01） |
| 身份揭露 | 伏线回收、自己发现或第三方揭破、阶梯式揭面、围观剧变、微表情、关系重构、暗示更深秘密 | 分阶段释放 |
| 觉醒或突破 | 见上文峰值类型 | 现代背景术法控量（G4-06）；奇观不靠血腥扭曲 |
| 情感高潮 | 氛围铺垫、缓慢接近、数行无对白、一句极简台词、闪回呼应、画面定格 | 克制，不写身体部位与性暗示；不称赞出轨（M8-02） |
| 卡点集 | 前 2 集蓄力、推到不可调和、临界一击、关键信息将完成时停住 | 只写"（本集完）" |
| 虐与转折 | 前置铺垫、先让观众喜欢、虐后给希望 | 打压后必有反击与反馈（M5-06）；施暴场面与痛苦表情控量（M8-04） |

## 正文格式

```
第二十三集

23-1 地点 时间 内/外
出场人物：甲，乙，系统

△动作行（可画，主语明确）。
甲（语气）：台词。
【VO】系统（甲脑中响起）：台词。
乙（OS）：台词。
【字幕：丙/身份】（重要角色首次出场）

（本集完）
```

台词括号里只写语气；一句台词服务一个目的；不堆破折号，不用"不禁、不由得、涌起一股、眸子、一抹"之类 AI 高频词；不混入小说原句（M5-13）。

## 交付

1. **正文**：纯剧本，按集顺序，即投稿模板第 13 项
2. **创作备忘**（另起）：每集字数与累计字数；峰值与结尾悬念类型；视觉奇观清单；本批新增角色与外形变化（供形象锚点卡更新）；伏笔登记；与分集卡的偏差及理由

## 写完自检

运行本 skill 目录 scripts/check_script.py（`--mode mj`）；交 mj-dx-visual 查可画性、一致性与旁白解说风险；交 mj-dx-rejection 抽查 12 类问题；红线风险点交 mj-dx-redline。定点回改，最多两轮。

## 示例

### 正例一：主场景（合格的单集片段）
**输入**：按分集卡写第 3 集。
**输出**（片段）：
```
第三集

3-1 杂役峰废料场 日 外
出场人物：沈烬，赵玄，众杂役
△沈烬从废料堆里抽出一截断剑，剑身锈成褐色。
众杂役（窃笑）：烧炉的捡破烂了。
△沈烬把断剑塞进炉膛，左手按在铁链上，炉火由红转金。
△炉盖弹开，一柄青光短刃悬在半空，周围的落叶全部静止。
赵玄（脸色一变）：灵器？你偷的谁的？
沈烬：你可以去问这堆废料。
（本集完）
```
**为什么好**：动作行可画、主语明确、一行一个动作（M3-04）；奇观服务剧情；纯剧本，无标注（M2-08）。

### 正例二：边缘场景（单集篇幅）
**输入**：漫剧单集写多少字？
**输出**：单集观看 1 到 2 分钟（M1-02）；全剧超过 70 集、不低于 7 万字（M1-01），折合每集约 1000 字。每集 2 到 4 场即可。

### 反例一：质量不足
**错误输出**：
```
△沈烬心中涌起一股难以名状的愤怒，他想起这三年受过的委屈，眼神变得深邃起来。
```
**问题**：心理描写无法生成画面（M3-04），AI 高频词堆叠（M5-13）。**改法**：写成"△沈烬攥紧铁链，指节发白"。

### 反例二：越界过度
**错误输出**：正文里夹着"镜头一：仰拍，景别中景；提示词：cinematic, 8k"。
**问题**：分镜和提示词属于成片衔接环节（mj-cr-handoff），不进投稿正文（M2-08、X-03）。

## 边界

- 不写分镜、提示词、角色资产卡（交 mj-cr-handoff）
- 分集卡有硬伤时先回 mj-cr-outline
